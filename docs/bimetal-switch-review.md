# 바이메탈 스위치 검토 보고

비상교육 p.101–103, 107. 모형 모드는 위·아래 금속과 온도로 휨을 관찰한다. 더 해 보기에서 접점 방식·방향·열원 위치와 주전자·장판을 고른다. 학습 모드는 6개 미션, 온도 반복 측정·평균·표·그래프·CSV, 확인 문제 3개를 더한다.

## 계산·가정과 검산

전체 두께 0.4 mm, 길이 25 mm, 같은 두께·탄성률의 두 층. α는 알루미늄 23, 놋쇠 19, 구리 17, 철(강철) 11×10⁻⁶/K. 기준 20 ℃, κ=3(α위−α아래)ΔT/(2h), 자유 처짐=κL²/2인 작은 기울기 근사다. 가열하면 작은 열팽창 금속 쪽, 냉각하면 큰 쪽으로 휜다. 숫자 처짐·공식은 교사 창에 둔다.

| 조건 | 독립 계산·검증 기준 | 엔진 |
|---|---|---|
| 구리 위·철 아래, 20→90 ℃ | 자유 끝 0.4921875 mm 아래 | 일치 |
| 같은 금속 두 층 | 팽창 차 0, 휨 0 | 모든 온도에서 일치 |
| 위·아래를 교환 | 같은 크기·반대 부호 | 일치 |
| 주전자 첫 0.05초 | 20+1500×0.05/4187=20.01791259 ℃ | 일치 |
| 주전자 바이메탈 첫 간격 | 명시적 적분으로 아직 20 ℃ | 일치 |
| DT 0.05→0.025초 | 최종 물·판 온도 및 차단 시각 수렴 | 각 차이 0.1 이내, 온도 약 0.00005 ℃ |

두 모드×16 금속 조합×5온도 총 160조건 해석식과 일치했다. 열원 위치는 전체 균일 온도 가정에서 방향을 바꾸지 않는다. 꺼지는 접점은 작은 변형을 따라가는 유연한 접점으로 단순화한다. 켜지는 접점이 끝을 막으면 끝 힘의 캔틸레버 변형을 중첩해 접점을 뚫고 지나가지 않게 한다. 기기에서 떨어진 접점의 이동 그림은 원리도다.

주전자 C=4187 J/K, 출력 1500 W, 손실 5 W/K, 공기 20 ℃, 바이메탈 응답 30초. 구리·철은 257.1초에 차단하고 걸쇠가 유지되어 15분 동안 재점등 0회. 매 계산 간격으로 확인한 최대 물 온도 99.311639 ℃, 900초 물 56.804809 ℃. 놋쇠·구리는 259.75초에 100 ℃에 도달해 관찰을 끝내고 끓는 중임을 표시했다. 이후 기화는 이 실험에서 계산하지 않는다.

장판 C=300 J/K, 출력 180 W, 손실 3 W/K, 응답 5초. 이동 기준 0.18 mm에서 끄고 0.10 mm에서 다시 켠다. 구리·철 조합 15분 동안 접점 전환 16회, 최초 끔 60.75초·다시 켬 131.2초, 최고 47.324026 ℃. 실제 제품 설계·안전 온도를 예측하는 값으로 쓰지 않는다. 학습 측정 온도에만 ±0.2 ℃ 후 반올림을 넣는다.

## 미션·창의 장치·검토

실제 클릭·키보드로 6/6 완료: 데우기/식히기, 주전자 끄기와 별도 열원의 경보 켜기, 구리·철 냉각 예상, 온도만 바꾸는 변인, 같은 금속과 열원 위치 비교, 가열·냉각 규칙 선택. 확인 문제 3/3. 예상 전 기록, 같은 조건 반복으로 변인 완료를 막았다. 선택형만 채점한다.

창의 장치는 두 금속을 따로 놓았을 때의 선팽창 길이 변화 막대와 자유 휨 점선이다. 붙어 있는 층이 각각 자유롭게 늘어난다는 뜻이 아님을 문장으로 구별한다. 막대는 실제 선팽창량에 비례하고 모형 층과 함께 끈다. 그림의 휨은 가로 길이 비에 비해 4배이며 두께는 별도 확대한다. 전자 이동 애니메이션은 넣지 않는다.

- 물리 반박: 주전자 100 ℃ 초과와 냉각 뒤 자동 재점등 문제를 상한 종료·걸쇠로 고쳤다. 장판만 이력 특성에 따라 반복한다. 실제 최대 온도는 그래프 표본의 최댓값 대신 모든 계산 간격으로 확인했다.
- 교과서·오개념 반박: 주전자 자체 전원이 꺼진 상태에서 가열하라는 불가능한 미션을 없애고, 경보 켜기는 별도 열원의 직접 가열 장면에서 판정한다. 같은 금속·열원 위/아래를 비교한다. 놋쇠·강철 계수는 교과서와 맞췄다. 빈칸은 개별 선택 칩으로 받는다.
- 사용성 반박: 핵심 세 조작을 기본으로 두고 기기·접점은 접힌 항목으로 옮겼다. 기준 온도에서 길이가 늘어난다는 잘못된 문장을 변화 없음으로 수정했다. 접점이 판을 눌러 휨을 숨기는 그림 대신 유연한 접점과 자유 휨 점선을 사용했다.
