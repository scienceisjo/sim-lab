# 기체 실험실 v3 — 운동 가시성과 보기 선택 개선

대상은 비상교육 p.199–201, 206–213, 214–215의 기체 핵심 개념이다. 사용자 피드백에 따라 2026-09-27에 PhET와 자바실험실을 브라우저로 직접 조작한 뒤 개선했다. 교사 확인 전이며 갤러리 등록·push·merge·배포는 하지 않는다. v2의 최초 검증 이력은 syringe-particles-review.md에 남아 있다.

## 직접 비교한 참고 화면

- [PhET Gas Properties](https://phet.colorado.edu/sims/html/gas-properties/latest/gas-properties_en.html?screens=2): 입자 수를 150개로 늘리고 가열 조작을 했다. 300 K에서 306 K로 변하는 온도 표시, 재생 중인 입자, 분명한 일시정지 단추와 대비가 높은 입자 표현을 확인했다.
- [자바실험실 샤를의 법칙](https://javalab.org/ko/charles_law/): 그래프 위 온도 조작점을 끌어 0 ℃ 부근에서 약 273 ℃ 부근으로 이동했다. 조작하면서 입자 운동이 이어지고 용기 부피와 그래프 위치가 함께 변하는 표현을 확인했다.

참고한 것은 조작의 연속성·시각적 대비·조건과 결과의 연결이다. 코드·그림·설명을 복사하지 않았다. 입자 속력의 온도 의존성이나 일정 압력의 해석은 자체 법칙·가정에 따라 검증했다.

## 발견한 원인과 변경

기존 온도 손잡이는 값이 바뀔 때마다 공통 rewind를 호출하여 재생을 멈추고 입자 배치를 처음부터 만들었다. 20→80 ℃에서 RMS 속력의 실제 차이도 약 9.76%로 작아, 정지 화면과 작은 입자에서는 변화를 알아보기 어려웠다.

- 기체 실험실은 열면 바로 움직인다. 예상을 먼저 골라야 하는 학습 미션의 재생 잠금은 유지한다.
- 손잡이를 바꾸면 새 평형 상태로 갱신하되 재생 여부를 유지한다. 일시정지한 경우에는 자동으로 다시 시작하지 않는다. 온도에 맞게 모든 속도 성분을 같은 비율로 조정하고, 상대적 위치와 운동 방향을 유지한다.
- 용기 높이를 175→240모형길이로 키우고, 표시 입자 반지름을 3→5로 키웠다. 어두운 용기 안 밝은 입자로 대비를 높였다. 대표 입자 크기는 모든 온도에서 같다.
- 모든 온도에 동일한 표시 축척을 적용하여 20 ℃ 초기 속력을 70→150모형길이/모형초로 바꿨다. 온도가 높을 때만 별도의 과장 배율을 곱하지 않는다. DT는 1/240초다.
- 노란 입자 한 개에 최근 0.4모형초의 실제 이동 경로를 표시한다. 이 자취는 충돌을 포함하며, 한 입자의 속력이 전체 평균과 같다는 뜻이 아니다. 자취를 끌 수 있다.
- 온도 탐색을 0–300 ℃로 넓히고 20 ℃·200 ℃ 비교 단추를 넣었다. 특정 물질의 상태 변화를 재현하는 것이 아니라 이상 기체의 관계를 보는 범위임을 밝힌다. 절대영도 외삽이나 모든 실제 기체가 이 범위에서 이상적이라는 주장은 하지 않는다.
- 보기 선택은 고정된 두 단추다. 기체에서는 「장치만 | 입자 보기」, 다른 실험실에서는 「실제 모습 | 모형 보기」다. 선택된 쪽에 체크·진한 배경·aria-pressed를 표시한다. 두 단추를 키보드로 선택할 수 있다. 공통 틀의 cfg.viewLabels로 이름을 지정한다.

기존 세 장면·두 모드·미션 6개·확인 문제 3개·측정 기록장은 유지한다. 온도 범위 확장에 따라 진행과 기록 저장 버전을 3으로 올렸다. 모형 모드는 깨끗한 값이며 학습 모드만 기존 측정 흔들림을 쓴다.

## 계산과 손계산 대조

같은 양의 기체에서 P=40/V(20 ℃), V=40(T+273.15)/293.15(1기압), RMS 속력 지표=100√((T+273.15)/293.15)다. 정량식은 교사용 설명에만 둔다.

| 온도 | 손계산 부피(mL) | 모형 부피(mL) | 손계산·모형 운동 지표(20 ℃=100) |
|---|---:|---:|---:|
| 20 ℃ | 40.000000 | 40.000000 | 100.000000 |
| 80 ℃ | 48.186935 | 48.186935 | 109.757614 |
| 200 ℃ | 64.560805 | 64.560805 | 127.044092 |
| 300 ℃ | 78.205697 | 78.205697 | 139.826407 |

섭씨 20→200 ℃는 숫자가 10배지만 운동 지표는 약 1.2704배다. 눈에 잘 보이게 한다는 이유로 이 관계를 바꾸지 않았다. 20 ℃의 부피 20·40·60 mL에서 압력 2·1·2/3기압도 다시 대조했다.

양 모드 38조건과 11조건×120모형초 입자 운동을 검증했다. 에너지 상대오차 최대 1.30×10⁻¹⁵, 경계 이탈 0, 시간 호출을 1/60초와 1/120초로 나누었을 때 상태 일치. 원판 충격량 평균과 점 입자 기준의 차이는 최대 약 2.69%였다. 도해용 원판 통계를 정밀 기압 센서에 사용하지 않고 센서값은 이상 기체식으로 계산한다.

20·80·200·300·0·20 ℃로 연속 변경할 때 속도 성분 비율·상대적 위치·전체 운동 지표를 검사했다. 새 조건에서는 충돌 통계와 자취를 비워 다른 조건의 관측을 섞지 않는다. 변인을 바꾸는 순간의 위치 재배치는 충분히 기다린 새 평형 상태를 준비하는 모형이며, 빠른 압축의 일·열 교환이나 피스톤의 과도 운동을 계산했다고 주장하지 않는다.

## 세 관점의 자체 반박 검토

물리: 온도별 과장 배율 대신 모든 온도에 같은 표시 축척을 적용했다. 속력의 제곱근 관계와 에너지 보존을 확인했다. 재생 빠르기를 온도 변화로 해석하지 않도록 안내를 유지했다. 300 ℃까지 이상 기체 범위를 넓힌 한계를 명시했다.

교과서·오개념: 입자 자체 크기·수는 가열해도 변하지 않는다. 온도 일정 비교에서는 전체 운동 지표가 같고, 압력 일정 비교에서는 부피도 함께 변한다. 노란 자취 한 개의 길이가 항상 평균 속력을 대표하지 않는 한계를 설명했다. 두 평형 상태 사이의 즉각적인 재배치를 실제 급가열·압축의 시간 과정으로 제시하지 않는다.

사용성: 현재 상태와 다음 동작을 섞었던 한 단추를 없애고 두 선택지를 항상 보여 준다. 움직이는 중/일시정지 상태도 실험판에 표시한다. 작은 입자의 대비와 크기를 개선하고 두 비교 온도 단추를 추가했다. 공통 변경을 기존 18개 실험실에서 검사했다.

남은 확인은 교사의 수업 적합성·운동 차이 체감, 실제 터치 기기·스크린리더 사용성이다. 외부 검토를 받았다고 주장하지 않는다.
