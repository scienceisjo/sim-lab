# 확산·증발 입자 관찰실 검토 보고

비상교육 p.113–120, 152. 모형 모드는 물속 잉크·공기 중 향수·저울 위 아세톤을 선택하고 양, 창문, 입자 자취를 조작한다. 학습 모드는 6개 미션, 반복 측정·평균·기록·그래프·CSV와 3개 확인 문제를 더한다. 확산 관찰과 질량 측정의 기록장을 분리했다.

## 계산·독립 검산

확산은 같은 질량의 탄성 원판 충돌과 벽 반사다. 물 표지 440개도 움직인다. 향수 장면에는 공기 200개가 있다. 초기 속도는 가우스 분포이며 전체 평균 속도를 제거한다. 열린 창문을 나간 향수는 밖으로 나간 수에 보존하고 새 공기 표지로 대체한다. 바람은 더하지 않는다. 실제 물의 인력·점성 전체나 실제 환기 흐름을 재현하는 모형은 아니다.

증발은 일정한 온도에서 얇은 젖은 막의 면적이 남은 양에 비례하는 전달 모형이다. L→G, G→L, G→O 전달율은 각각 0.035, 0.002, 0.08 /모형초. 실제 아세톤 건조 시간의 보정값이 아님을 학생·교사 창에 명시했다. L+G+O가 보존되고 저울에는 L만 포함한다. 각 대표 입자는 0.001875 g, 방울당 8개다. 표시층은 질량 이동 도해이며 분자 궤적이라고 부르지 않는다.

| 잉크 1방울+물 | 15+440=455개 | 455개 유지 |

독립 해는 dL/dt=−aL+bG, dG/dt=aL−(b+c)G의 고유근 두 개로 계산했다. 단일 표본과 기댓값은 구별한다. 한 번에 60초와 0.1초씩 600회 계산한 사건 결과도 일치한다. 두 모드의 입자 운동·수치는 같으며 학습 저울에만 ±0.001 g를 더해 소수 둘째 자리로 표시한다. 반올림을 포함한 기록 허용 범위는 ±0.006001 g다. 0.00 g 표시에도 대표 입자가 남을 수 있음을 명시했다.

## 미션·화면·반박 검토

실제 클릭으로 6/6: 세 장면 탐색, 물 입자 운동 예상, 향수 감지와 열린 창문, 액체 감소와 총량 보존, 시간만 바꾸는 변인, 확산·증발 정리. 확인 문제 3/3. 예상 전 재생 잠금, 같은 시간 반복만으로 변인 통과 불가, 다른 미션의 실험 재활용 방지를 확인했다.

창의 장치는 물·공기 입자 한 개의 자취와 액체/공기/바깥 보존 장부다. 자취는 의도적인 이동 경로가 아니며 감지 순서가 언제나 거리 순서라고 채점하지 않는다. 모형 층을 끄면 입자·자취를 숨긴다. 장부 그림의 칸은 실제 공간·분자 크기 비율을 뜻하지 않는다.

- 물리 검토: 미보정 Lennard–Jones 계를 아세톤 액체라고 부르는 설계를 버렸다. 전달 사건을 전체 사건 시각 순으로 처리하여 프레임 간격에 따라 결과가 달라지던 문제를 수정했다. 공중 기체 질량을 저울에 더하지 않는다.
- 교과서·오개념 검토: 물 입자도 움직인다. 기체가 바닥에 쌓이지 않는다. 증발은 표면에서 나타내고 내부 기포를 그리지 않는다. 창밖 향수가 공기로 변했다고 오해하지 않도록 경계의 유출·유입을 설명했다. 기화와 확산, 질량 감소와 소멸을 구별했다.
- 사용성 검토: 빈 접시일 때만 영점을 맞춘다. 안정적인 입자 ID로 자취가 다른 입자로 바뀌지 않게 했다. 질량과 입자 수의 기록을 분리하고 키보드 조작·그래프 데이터 표를 제공한다.
