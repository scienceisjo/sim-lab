# 알짜힘과 운동 상태 변화 검토 보고

비상교육 중1 p.178–184. 모형 모드는 정지, 바람 없음, 앞·뒤·옆 바람, 줄에 매단 공, 줄 끊기, 비스듬히 던진 공을 선택하고 재생한다. 학습 모드는 같은 모형 위에 7개 미션, 측정 기록장, 일괄 분류표, 확인 문제 3개를 더한다.

## 계산과 가정

질량 0.05 kg, 처음 속력 0.6 m/s, 바람 힘 0.01 N을 고정한다. 수평 마찰·공기 저항을 무시하고 바람이 2초 동안 일정한 힘을 준다고 단순화했다. 앞바람 뒤에도 공은 전진하므로 ‘속력만 변함’이 유지된다. 원운동은 반지름 0.5 m, 속력 0.6 m/s이며 줄은 중심으로 당긴다. 줄이 1초에 끊긴 뒤에는 그 순간의 접선 방향으로 등속 운동한다. 투사체는 초기 속도 (1.2,2.4) m/s, g=9.8 m/s²이고 착지 직전 관찰을 마친다. 반발과 착지 후 운동은 생략한다. 내부 운동 법칙은 그대로 계산하며 F=ma·관성·구심력이라는 이름은 학생 화면에 넣지 않았다.

해석해를 1/120초 고정 간격으로 표본화하고, 재생 중 최대 속력 차이와 처음 방향에서의 최대 각도를 누적한다. 기준은 max(0.05 m/s, 처음 속력의 3%) 및 3°다. 시작과 끝만 비교하지 않으므로 한 바퀴 원운동과 같은 높이로 돌아온 포물선도 정확히 분류한다.

판 위 옆모습 창에는 중력과 바닥 힘이 평형으로 작용한다. ‘바람 없음’을 ‘힘 없음’으로 부르지 않는다. 위 모습의 힘 축척은 0.01 N=20 논리 px이고, 옆모습은 0.1 N=14 px로 별도 표시한다. 합력을 추가 힘처럼 겹치지 않는다.

창의 장치는 일정 시간 자국과 운동 방향 나침반이다. 자국은 판 0.25초, 투사체 0.05초 간격이다. 파란 점선 나침반은 힘이 아니며 길이는 속력을 뜻하지 않는다. 모형 층과 함께 끌 수 있다. 측정 속력만 ±0.01 m/s 흔들린 뒤 반올림하고, 경로와 분류에는 흔들림을 넣지 않는다.

## 손계산 대조

| 사례 | 손계산 | 자동 검증 |
|---|---|---|
| 바람 없음, 2초 | x=1.2 m, 속력 0.6 m/s, 변하지 않음 | 일치 |
| 뒤 바람, 2초 | x=1.6 m, 속력 1.0 m/s, 속력만 | 일치 |
| 앞 바람, 2초 | x=0.8 m, 속력 0.2 m/s, 속력만 | 일치 |
| 옆 바람, 2초 | x=1.2 m, y=0.4 m, 속력 √0.52≈0.72111 m/s, 둘 다 | 일치 |
| 원운동 한 바퀴 | 속력 0.6 m/s, 처음 위치로 복귀, 방향만 | 일치 |
| 줄 끊은 뒤 구간 | 속력 차이 0, 방향 차이 0 | 일치 |
| 투사체 착지 직전 | 처음과 같은 속력 √7.2≈2.68328 m/s | 일치 |
| 투사체 정점 부근 | 최소 속력≈1.2 m/s, 최대 차이≈1.48328 m/s, 둘 다 | 표본 간격 오차 0.001 이내 |

두 모드 총 16사례가 일치했다. 해석해 값은 10⁻⁷, 줄 끊은 뒤 각도는 10⁻⁵도 이내다. 원운동과 포물선의 최대 방향 변화가 누적되는 것을 확인했다.

## 미션·화면·자체 반박 검토

실제 클릭·재생으로 7/7 미션을 통과했다: 세 사례 탐색, 바람 세 방향 비교, 알짜힘 0 예상, 줄 끊기 전후, 변인 설계, 여덟 사례 분류, 바닥 힘 정리. 예상 전 재생 잠금, 관찰 전 기록 차단, 같은 조건 반복으로 변인 통과 불가, 현재 미션에서 관찰하지 않은 분류 차단, 모든 답을 고르기 전 채점 차단을 확인했다. 일부러 틀린 포물선 분류는 재관찰 안내를 보인 뒤 수정해야 통과했다. 확인 문제 3/3 통과.
