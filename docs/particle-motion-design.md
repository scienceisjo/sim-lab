# 확산·증발 입자 관찰실 설계 카드

비상교육 p.113–120, 152. 잉크 1–2방울, 향수 3–4회, 전자저울·거름종이 위 아세톤 몇 방울을 다룬다. 핵심 조작은 장면과 처음 넣은 양, 향수 장면의 창문이다. 온도·바람 세기·습도·입자 질량 비교는 p.113 지도 범위에 맞춰 제외한다. 물·공기 입자도 움직이며, 따로 켜는 자취는 물 입자를 기본 대상으로 한다.

확산은 같은 질량의 2차원 탄성 원판 운동을 사용한다. 초기 속도의 두 성분은 가우스 분포에서 뽑고 전체 질량중심 속도를 제거한다. 원판 충돌과 벽 반사로 방향이 바뀌며, 농도가 낮은 쪽을 찾아가도록 조종하지 않는다. 물속 장면은 조밀한 원판의 운동 모형으로 실제 물의 모든 인력을 재현하지 않는다. 향수 장면은 희박한 원판이며 닫힌 창문에서는 외부 흐름이 없다. 열린 창문을 넘은 향수는 밖으로 나간 수에 보존하고 깨끗한 공기 표지로 대체한다. 일정한 바람 속도를 더하지 않는다. 실제 환기에는 공기 흐름도 있지만 이 장면은 확산만 분리한 이상화다.

증발은 미보정 2D Lennard–Jones 액체를 실제 아세톤이라고 부르지 않는다. 기존 설계의 임계점 부근 설정·내부 기포·상태 오판정을 피하고, 얇은 젖은 막과 공기·방 바깥 사이의 질량 전달 모형을 사용한다. 같은 온도에서 유지되는 얇은 막의 젖은 면적이 액체 양에 비례하고, 단위 면적의 순방향 전달 계수가 일정하다고 가정한다. 액체→표면 위 기체, 기체→액체, 기체→바깥의 1차 전달을 각각 a=0.035, b=0.002, c=0.08 /모형초로 둔다. dL/dt=−aL+bG, dG/dt=aL−(b+c)G, dO/dt=cG이며 총량이 보존된다. 각 대표 입자의 지수 대기시간으로 같은 전달 과정을 표본화한다. 실물 아세톤의 건조 시간·증기압·분자 간 힘을 예측하는 수치가 아니다. 입자 움직임은 표시층이며 전달율을 실제 분자 충돌 계산에서 도출했다고 주장하지 않는다.

액체에서 기체로의 이동은 액체 표면에서만 그린다. 액체 내부 기포를 그리지 않는다. 저울에는 액체에 남은 양만 포함하고 화면 안 기체·방으로 나간 양을 더하지 않는다. 합계는 액체+화면 안 기체+방으로 나감=처음으로 항상 표시한다. 1방울은 0.015 g이라는 설명용 가정, 방울당 대표 입자 8개, 기본 5방울 0.075 g. 표시 0.01 g에서 0.00은 입자가 모두 사라졌다는 뜻이 아님을 안내한다. 되돌아오는 입자는 질량을 다시 액체에 더하며, 대체로 질량이 감소하는 열린 계를 보여 준다. 기화의 열에너지와 끓음 비교는 뒤 실험실에서 다룬다.

미션: 세 장면 탐색, 물 입자도 움직이는지 예상·자취, 바람 없는 향수 확산과 열린 창문으로 나감, 아세톤 저울 감소와 총량 보존, 시간만 바꾸는 변인, 개념 정리. 확인 문제 3개. 먼 자리는 대체로 늦지만 무작위 운동 때문에 순서가 항상 거리에 비례한다고 채점하지 않는다. p.152는 기화와 확산을 구별하는 생활 설명으로 연결한다. 암모니아 지시약과 방향제 제작은 해당 쪽의 실물 활동으로 교사 창에서 연결한다.

창의 장치는 한 입자의 궤적과 액체/공기/바깥의 보존 장부다. 궤적은 정해진 방향으로 가려는 의도가 아니고, 넓게 퍼진 뒤에도 계속 움직인다. 물질 색·입자 크기는 속력이나 위치에 따라 바뀌지 않는다. 모형을 끄면 보이지 않는 기체 입자와 자취를 숨긴다. 학습 저울만 ±0.001 g, 모형 시간·입자 수는 흔들리지 않는다. 검증은 충돌 에너지·입자 수, 전달 방정식의 독립 해와 표본 평균, 실제 미션, 네 화면, 세 관점 반박으로 한다.
