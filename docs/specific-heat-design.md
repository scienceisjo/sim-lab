# 비열 설계 카드

비상교육 p.96–99, 104, 107. 물·식용유 각 50 g을 같은 장치로 5분 가열하고, 60 ℃에서 같은 방에 두어 냉각하는 실험이다. 모형은 공급 열 막대와 온도 곡선이다. 비열 차이를 입자 크기·빠르기의 차이로 원인 설명하지 않는다. 핵심 조작은 가열/냉각과 두 시료 종류, 추가 양 조작은 접힌 더 해 보기에 둔다. 학생 용어는 질량 대신 양(g)이다.

상대 비열은 교과서의 철 0.107, 모래 0.191, 알루미늄 0.214, 콩기름 0.47, 에탄올 0.568, 물 1을 쓰고 내부 단위 환산은 4187 J/(kg K)를 곱한다. 같은 출력 20 W, 주변 20 ℃와 열손실 0.15 W/K의 해석해로 계산한다. 용기의 열용량은 무시하고 시료가 고르게 데워진다고 가정한다. 공급 열은 P×시간이며 손실 뒤 시료에 남는 열과 구별한다. 냉각에서는 두 시료가 잃은 열이 같지 않으므로 같은 열 막대를 숨긴다.

한 시료가 80 ℃(에탄올 70 ℃)에 닿으면 두 가열 장치를 함께 끄고 같은 시각에 관찰을 끝낸다. 끓음은 다루지 않는다. 에탄올은 실물 가열 실험에 쓰지 않는다는 교과서 안내를 보여 준다. 고체에는 센서를 꽂지 않고 모형 온도 표지를 붙인다. 물과 식용유의 액체 높이는 양과 대표 밀도에 따라 달리 그려 같은 g이 같은 부피라는 오해를 막는다.

미션은 가열/냉각 탐색, 물·식용유 비교, 같은 양 알루미늄/물 예상, 재료만 바꾸는 변인 설계, 여섯 물질 비열 순서 일괄 판정, 프라이팬·찜질 팩 적용이다. 순서 미션은 현재 미션에서 20→40 ℃에 도달한 기록만 근거로 쓰고, 가까운 모래/알루미늄은 직접 비교 기록이 필요하다. 0.1초까지 걸린 시간을 표시하고 모든 순서를 고른 뒤 채점한다. 측정값 ±0.2 ℃, 확인 문제 3개.

창의 장치는 두 공급 열 막대와 온도 곡선이다. 같은 높이의 공급 열에도 온도 변화가 다름을 보여 준다. 주변으로 새는 열까지 시료에 남는다고 오해하지 않게 하고, 냉각에서는 같은 열을 잃는다는 표시를 하지 않는다. 막대는 실제 P×시간에 비례하며 모형 층과 함께 끈다.
