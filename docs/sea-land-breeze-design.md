# 해풍·육풍 설계 카드

비상교육 p.97, 99, 108. 같은 양의 모래와 물 두 칸에 같은 햇빛을 비추는 열 모형과 해안 순환의 흐름 표지를 연결한다. 핵심 조작은 시각, 왼쪽 물질, 오른쪽 물질이다. 14시·2시 바로가기와 하루 재생을 제공한다. 공기 점은 분자 아닌 흐름 표지이며 상자로 가두는 그림을 쓰지 않는다. 모형을 끄면 흐름·햇빛 화살표를 숨긴다.

열용량 물 2.0×10⁶ J/(m² K), 모래는 그 0.191배. S(t)=300 max(0,sin[π(t−6)/12]) W/m², 외부 20 ℃, 손실 25 W/(m² K). 같은 양·같은 햇빛이며 C dT/dt=S−25(T−20)를 DT=60초로 계산한다. 한 간격 동안 중간 시각의 햇빛을 일정하게 둔 정확해를 쓰며 20일 예비 계산으로 반복되는 하루에 가깝게 만든다. 새 설정은 같은 반복 조건의 하루를 다시 계산한 것으로, 즉시 실제 바다가 모래로 변하는 사건을 재현하지 않는다.

상대 순환 세기는 두 칸의 온도 차를 20분의 시간 상수로 따라가는 선형 응답 근사다. 실제 풍속을 제시하지 않는다. 순환의 흐름 함수 ψ=A sin(πx)sin(πz)에서 속도 성분을 계산하여 연속된 상승·상층 이동·하강·지표 이동을 그린다. 전환 직후에는 온도 차와 흐름 방향의 반응 지연을 명시한다. 기압·전향력·계절풍·일기 예측은 학생 화면에 없다.

미션: 하루 재생, 14시와 2시 관찰, 두 칸 모두 모래 예상, 시각만 바꾸는 변인, 바다가 있던 자리를 모래로 바꿨을 때 그 칸의 일교차 비교(p.99 아랄해 연결), 낮·밤 설명 선택. 기록은 학습 온도 ±0.2 ℃ 후 반올림, 반복 평균·CSV·그래프와 확인 문제 3개다. 두 칸은 열적으로 독립이라 오른쪽을 바꾸어도 왼쪽의 온도 범위가 달라진다고 주장하지 않는다. 실제 아랄해 주변 기후 전체를 예측한 값이 아님을 밝힌다.

창의 장치는 하루 그래프의 현재 시각 자와 닫힌 순환의 흐름 표지다. 차가운 쪽에서 따뜻한 쪽으로 지표 공기가 이동하는 이유를 상승·하강과 연결하되 물질 전체가 바다와 땅 사이로 이동하거나 공기 분자가 한 방향으로만 움직인다는 뜻이 아니다. 동일 물질이면 두 온도와 모든 상대 순환이 정확히 같아 바람이 0이 되는 반례를 둔다.
