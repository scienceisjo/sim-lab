# 탄성력 검토 보고

비상교육 중1 p.166–169. 모형 모드는 고정한 용수철을 당기고 누르는 장면, 종류 선택, 양 끝 확대 창을 제공한다. 학습 모드는 같은 계산 위에 6개 미션, 반복 측정·평균·표·그래프·CSV 기록장, 확인 문제 3개를 제공한다.

## 계산·가정과 오개념 방지

원래 길이 30 cm, 변형 −10~25 cm. 준정적 평형에서 A는 0.072 N/cm, 비교용 B는 0.12 N/cm로 F=k|x|이다. 센서가 받는 탄성력은 −kx, 고정부가 받는 힘은 +kx다. 본체 축척은 1 N=40 논리 px이고 확대 창은 2배다. 전체 길이와 늘어난 길이를 함께 보여 주고, 압축 기록을 신장 그래프에 섞지 않는다. 전체 길이–힘 관계도 직선일 수 있으나 정비례가 아님을 교사용 설명에 적었다. 진동·영구 변형·직렬/병렬은 다루지 않는다.

창의 장치인 양 끝 확대 창은 고정점에도 힘이 작용함을 보여 준다. 같은 용수철의 양 끝을 분리한 그림이며 새 물체나 추가 힘을 뜻하지 않는다. 끌 수 있으며 창을 꺼도 본체 힘은 유지된다. 모형 층을 끄면 모든 힘 보조 표현을 숨긴다.

## 미션·검산

미션: 탐색 → A의 5·10·15·20 cm 측정 → 25 cm 예상 → 압축/신장의 방향 비교 → 늘어난 길이만 바꾸는 실험 설계 → 전체 길이와 늘어난 길이 구별. 실제 키보드·클릭으로 6/6 통과했다. 확인 문제는 길이 구별, 두 배 관계, 압축 방향으로 3/3 통과했다. 예상 전 기록 차단, 압축 기록 차단, 한 조건 반복만으로 변인 미션을 완료할 수 없음을 확인했다.

| 조건 | 손계산 | 검증 |
|---|---:|---|
| A, 5 cm 신장 | 0.36 N, 센서에는 왼쪽 | 일치 |
| A, 10 cm 신장 | 0.72 N | 일치 |
| A, 15 cm 신장 | 1.08 N | 일치 |
| A, 20 cm 신장 | 1.44 N | 일치 |
| A, 25 cm 신장 | 1.80 N | 일치 |
| A, 10 cm 압축 | 0.72 N, 센서에는 오른쪽 | 일치 |
| B, 5 cm 신장 | 0.60 N | 일치 |
| 변형 0 cm | 0 N | 일치 |

두 모드 28개 수치 사례의 힘·방향·전체 길이를 10⁻⁹ 이내로 대조했다. 측정은 ±0.01 N 흔들림 뒤 소수 둘째 자리로 반올림한다. 반올림 0.005 N까지 포함한 저장 검사로 모든 정수 신장량·두 용수철·난수 양 끝 104/104 통과했다. 중력 24개와 합해 회귀 검사 128개다.
