# 중력 — 질량과 무게 검토 보고

교과서: 비상교육 중1 p.164–165. 모형·학습 두 모드, 두 저울·위로 던진 공·천체 전체의 세 장면을 제공한다. 개발·검증은 완료했으며 교사 확인 전이므로 갤러리 등록과 썸네일은 아직 추가하지 않는다.

## 계산과 오개념 방지

지구 9.8 N/kg, 달 9.8/6 N/kg로 W=mg. 물체를 바꿔도 힘 화살표는 1 N=3 논리 px이며 장소 전환에도 고정한다. 질량은 1–6 kg이다. 6 kg은 100 N 큰 용수철저울, 1–5 kg은 50 N 힘 센서로 표현한다. 저울 장면은 정적 평형이다. 센서가 당기는 힘은 부착점에서 위로, 중력은 물체 중심에서 아래로 그린다. 큰 용수철저울의 변형도 무게에 비례한다.

양팔저울은 같은 팔 길이의 양쪽에 물체와 분동을 올린다. 지구와 달 모두 질량이 같을 때 수평이다. 질량 차가 있을 때의 기울기는 질량 비교용이며 각도를 질량 눈금으로 사용하지 않는다. 천체 전체 그림은 실척도가 아니며 힘 방향을 이해하기 위한 그림이다.

공은 초기 위쪽 속도 3 m/s, 공기 저항 없음. 1/120초 간격으로 y=3t−gt²/2, v=3−gt를 계산한다. 바닥으로 돌아온 순간 관찰을 멈추고 튕김은 다루지 않는다. 상승·정점·하강에서 중력 방향이 바뀌지 않는다. 학습 센서의 ±0.04 N 흔들림은 물리 계산과 화살표에 영향을 주지 않는다.

창의 장치는 같은 눈금에 나란히 놓은 지구·달 무게 막대다. 같은 질량인데 무게만 6:1인 관계를 드러낸다. 막대는 천체의 크기나 거리 모형이 아니며, 모형 층과 함께 끌 수 있다.

## 미션과 확인 문제

미션 6개: 같은 물체를 두 곳으로 옮기기 → 6 kg 지구·달 예상과 기록 → 같은 분동으로 양팔저울 맞추기 → 상승·하강의 중력 관찰 → 장소만 바꾸는 변인 설계 → 질량·무게·중력 방향 정리.

확인 문제 3개: 달에서의 질량(6 kg 유지), 지구 2 kg 물체의 무게(19.6 N), 공이 정점에 있을 때 중력(아래). 오답별로 질량/무게 단위 혼동과 이동 방향/힘 방향 혼동을 짚는다.

## 세 관점 자체 반박 검토

- 물리: 지구·달 전환 시 화살표 축척이 달라져 6분의 1이 사라지는 오류를 방지했다. 큰 추를 저용량 센서에 거는 장면을 제외했다. 용수철저울의 변형과 무게 관계를 확인했다.
- 교과서·오개념: 공이 올라가도 중력은 아래, 달에도 중력이 있음, 양팔저울로 비교하는 질량은 그대로라는 내용을 각각 조작·미션·문제로 연결했다. 정밀 저울 각도나 만유인력 공식을 학생 학습 내용으로 넣지 않았다.
- 사용성: 긴 공기 저항 설명을 두 줄로 나누고, 천체 아래쪽 물체가 안내문과 겹치지 않게 배치했다. 중력 관찰 미션은 화살표가 보이는 상태에서 상승과 하강을 관찰해야 통과한다.
