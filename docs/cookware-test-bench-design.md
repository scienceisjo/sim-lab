# 조리 도구 재료 비교·열변색 설계 카드

비상교육 p.95, 97–99, 103–105, 109. 종이 설계 활동을 돕는 비교 시험대다. 실제 음식 익음·화상·파괴를 예측하지 않는다. 모형은 같은 양·같은 가열 조건의 불판 비교, 같은 처음 온도에서의 받침 냉각, 같은 온도 변화에서의 길이 비교다. 이 세 결과는 조립된 도구의 한 시각이 아니라 부품을 따로 시험한 결과임을 밝힌다.

핵심 선택은 불판 철/알루미늄, 받침 철/알루미늄/물, 손잡이 잘 전도함/잘 전도하지 않음이다. 비열은 p.97의 상대값 철 0.107·알루미늄 0.214·물 1, 선팽창은 p.101의 강철 11·알루미늄 23×10⁻⁶/K만 쓴다. 불판 각 50 g을 20 W로 60초 가열, 주변 20 ℃·손실 0.15 W/K의 해석해를 쓴다. 받침 각 50 g은 60 ℃에서 같은 손실 조건으로 식힌다. 기본 10분, 더 해 보기에서 0–10분을 고른다. 길이 변화는 두 불판 모두 20→80 ℃, 처음 20 cm로 별도 비교한다.

손잡이는 교과서의 전도 성질 카드로만 비교한다. 알려지지 않은 열전도율·열팽창 계수를 지어내어 온도나 이음매 점수를 만들지 않는다. 서로 끝을 이어 붙인 부품을 바이메탈처럼 휘게 그리지 않는다. 실제 이음매는 팽창 차를 고려해야 한다는 설명만 둔다. 내열 유리를 불판 추천 목록에 넣지 않는다.

학습 미션은 부품 바꿔 보기, 지정 비교 기준에 맞는 조합, 한 부품만 바꾸는 변인, 같은 처음 온도에서 받침 냉각, 열변색 기준을 사이에 두고 관찰, 부품별 성질 정리다. 기준은 철 불판·물 받침·열이 잘 전달되지 않는 손잡이가 교과서의 비교 목적을 충족하도록 공개한다. 보편적인 최고 조리 도구나 안전 보증으로 평가하지 않는다.

열변색(p.109)은 받침의 계산 온도에 반응하는 모형 스티커로 연결한다. 기본 기준 50 ℃, 더 해 보기에서 30–60 ℃ 설정. 이 수치는 교과서나 실물 재료의 값이 아니라 학생 설계용 가정이며 안전/위험 온도 판정으로 쓰지 않는다. 색과 '기준 이상/미만' 글자를 함께 바꾼다. 화학 원리·실제 변색 재료의 지연은 제외한다. 창의 장치는 부품별 비교 결과와 색이 바뀌는 온도 표지이며 모형 층으로 끈다. 학습 온도 측정만 ±0.2 ℃ 흔들림, 기록·평균·CSV·확인 문제 3개를 둔다.
