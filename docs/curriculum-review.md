## 범위와 두 모드

중학교 87개 성취기준의 개념 연결과 별도 활동을 [대응표](curriculum-coverage.md)에 기록했다. 이는 전체 성취기준의 수행·평가를 완성했다는 뜻이 아니다. 지속가능한 삶, 재해·재난과 안전, 과학과 나의 미래의 조사·토의·실천은 별도 활동으로 안내한다. 기존 교과서 기반 실험실의 쪽수는 기존 검토 문서에 남겼다. 신규 설계는 교육과정 코드로 출처를 표시하며 확인하지 않은 교과서 쪽수를 붙이지 않았다.

- 모형 모드: 실험판, 조건 조작, 상태가 표시되는 장면 보기/모형 설명 선택, 비교판, 가정. 측정값에 흔들림을 더하지 않는다.
- 학습 모드: 같은 계산·그림에 기록·미션·문제만 추가한다. 신규 미션 158개, 선택형 확인 문제 90개다. 잘못 고른 문제에는 해설을 표시한다.
- 수량 관계 모형 23개: 조건 비교 → 변인 설계 → 개별 과제 → 결과 설명. 실제 측정을 표현하는 항목만 작은 오차와 세 번 측정을 사용한다. 원자 수·확률·계산값에 임의 오차를 넣지 않는다.
- 구조·경로 관찰 모형 22개: 조건 비교 → 개별 관찰 과제 → 결과 설명. 관찰 기록에는 가짜 평균·그래프를 제공하지 않는다. 기록 표·CSV·저장·초기화는 동일하게 제공한다.

공통 비교판은 이전 조건의 관찰값을 고정하여 현재 결과와 비교하는 보조 장치다. 실제 물체나 에너지를 복제한 장면이 아니다. 세부 창의 장치와 한계는 각 설계 카드 및 선생님께 창에 기록했다. 키보드로 조건·보기·미션을 조작할 수 있고, 그림의 문장 설명과 그래프 데이터 표를 제공한다.

## 세 관점 반박 검토와 수정

이는 동일 개발자가 관점을 나누어 수행한 자체 검토와 자동 검증이다. 독립 전문가 검토를 받았다고 주장하지 않는다.

### 과학 정확성

- 화학 반응에서 남은 반응물까지 원자 수와 질량에 포함했다. 용해된 양과 남은 고체의 합도 확인했다.
- 병렬 회로의 같은 전류에 대응하는 표지 간격·속도를 같게 했다. 표지는 전자의 실제 이동 속도가 아니다.
- 파동의 종방향 입자 변위를 줄여 입자가 서로 추월하는 그림을 막았다. 파동 진행과 입자의 진동을 구별한다.
- 달 표면의 밝기는 3차원 법선과 태양 방향으로 계산한다. 위상은 지구 그림자가 아니다. 교점·기울기를 바꿔 매달 식이 일어나지 않는 배열을 표시한다.
- 세포분열은 DNA 복제와 감수 1분열을 추가하고, 염색체 수와 세포 수를 분리했다. 난할은 딸세포 부피 합을 보존한다.
- 빛의 중심 광선을 보완했다. 전하 도해는 원자핵을 고정하고 전자 수 변화를 표현한다.

### 교육과정·오개념

- 이산 개수와 범주에는 측정 잡음·평균을 억지로 붙이지 않는다. 광합성 환경 조건 모형은 정성 비교로 두고 가상의 실측 광합성률을 만들지 않는다.
- 식물 세포막을 세포벽 안쪽에 가깝게 그려 일반적인 세포가 원형질 분리된 것처럼 보이지 않게 했다.
- 세포분열 색은 염색체의 기원을 구별하는 표지다. 감수분열의 한 가지 배열을 모든 실제 분열의 유일한 조합으로 설명하지 않는다.
- 판 경계 지진·화산은 모식 분포임을 표시했다. 실제 발생 자료나 재난 예측 화면이 아니다.
- 태양 활동, 대기·해양 순환, 복사 평형은 선택한 관계의 단순 모형이다. 실제 날짜의 우주 날씨·지역 일기·CO₂ 농도별 기온 예보가 아니다.
- 별·은하의 표지는 실제 지름이 아니다. 팽창에서 은하 크기는 고정하며 관측 위치를 바꾸어도 특정 은하가 중심이 되지 않게 한다.

### 사용성

- 현재 선택을 확인할 수 있는 장면 보기/모형 설명 단추를 제공한다. 모형 설명의 목적도 바로 아래에 쓴다.
- 글자 자동 줄바꿈, 그림 영역 경계, 정전기 기호·하늘 운동 설명·바다 단면·운동 그래프의 위치를 조정했다.
- 비교판의 긴 관찰값은 캔버스에서 줄이고 전체 문장을 별도 텍스트로 제공한다. 처음부터·미션 초기화 시 비교 문장도 함께 지운다.
- 저장된 미션 배열을 그대로 읽어 지도 진행점을 표시하고, 단원 중복 연결을 고유 실험실 수에 중복 집계하지 않는다.

## 남은 범위와 교사 확인

45개 모두 같은 수준의 동역학 시뮬레이션은 아니다. 수량 관계 모형 23개와 구조·경로 관찰 모형 22개를 목적에 맞게 구별했다. 실제 장치의 세부 감각, 모든 조건에서의 물리·생리 반응, 야외 조사와 논증 수행은 포함하지 않는다. 화면의 모형·가정 안내를 수업에서 확인해야 한다. 조건 조합 검사는 대표·경계값 조합이며 가능한 모든 연속값을 전수 조사한 것이 아니다.

교사에게 직접 확인받기 전의 로컬 검토본이다. 주 갤러리 sims.js 등록·썸네일과 공개 배포는 이번 작업 범위에 포함하지 않았다. 이 보고서의 완료는 구현·로컬 검증 완료를 뜻한다.
