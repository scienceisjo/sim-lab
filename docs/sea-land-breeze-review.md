# 해풍·육풍 검토 보고

비상교육 p.97, 99, 108. 모형 모드는 시각과 두 칸 물질을 바꾸며 해풍·육풍 순환, 두 온도, 하루 그래프를 비교한다. 흐름 점은 공기 분자가 아닌 흐름 표지다. 학습 모드는 6개 미션, 반복 측정·평균·표·그래프·CSV와 확인 문제 3개를 더한다.

## 계산·가정과 검산

같은 양의 모래와 물, 같은 일사량을 가정한다. 열용량 C물=2×10⁶, C모래=382000 J/(m² K). C dT/dt=S(t)−25(T−20), S=300 max(0,sin[π(t−6)/12]) W/m². DT=60초, 간격 중간 시각의 일사량을 일정하게 두는 해석해를 쓴다. 20일 예비 계산 뒤 반복되는 하루를 비교하며 재생 1분이 하루다. 상대 순환은 온도 차를 20분 시간 상수로 따라가는 선형 응답이고 실제 풍속이 아니다.

| 조건 | 독립 기준 | 엔진 |
|---|---|---|
| 모래 20 ℃, 정오의 일정 일사량으로 첫 60초 | 20+12(1−exp[−25×60/382000])=20.047028 ℃ | 일치 |
| 연속 사인 일사량의 정확한 적분해 | 두 모드·4조합·7시각, 56조건 | 0.00004 ℃ 이내 |
| DT 60→30초 | 하루 모든 시각 온도 수렴 | 최대 차이 0.00000989 ℃ |
| 같은 물질 두 칸 | 온도 차와 상대 순환 0 | 물/물·모래/모래 정확히 0 |
| 반복 하루의 0시·24시 | 같은 온도 | 물 차이 약 10⁻⁹ ℃ |

기본 14시 모래 28.596821 ℃·물 24.649891 ℃, 지표 바다→육지. 2시 모래 20.963095 ℃·물 23.349931 ℃, 육지→바다. 하루 범위 모래 20.370122–28.781747 ℃, 물 22.743242–24.977380 ℃. 이는 모형 상수로 계산한 값이며 교과서 실측값이 아니다.

공기 흐름 함수 ψ=A sin(πx)sin(πz), A=−0.02u의 두 속도 성분으로 60개 표지를 이동한다. 상승·상층 이동·하강·지표 이동을 함께 그린다. 실제 지형·기압·전향력·해양 혼합·증발·날씨 전체를 재현하지 않는다. 화살표는 순환 방향 표시이며 실제 풍속 눈금이 아니다. 학습 기록 온도만 ±0.2 ℃ 후 반올림한다.

## 미션·창의 장치·반박 검토

실제 하루 재생·클릭·키보드로 6/6 완료: 하루 탐색, 14시/2시 비교, 모두 모래 예상, 시각만 바꾸는 변인, 바다 자리의 일교차 변화, 비열·낮밤·풍향 정리. 확인 문제 3/3. 시각 건너뛰기로 하루 관찰 완료, 예상 전 기록, 같은 조건 반복으로 변인 완료를 막았다. 24시 슬라이더 끝점도 키보드로 확인했다.

창의 장치는 전체 순환 표지와 하루 그래프 위 현재 시각 자다. 바다도 데워지고 식는 작은 변화를 볼 수 있다. 동일 물질에서는 그래프 두 선이 겹치며 바람이 사라지는 반례를 보여 준다. 순환과 온도 차는 반응 지연 때문에 전환 시각이 완전히 같지 않음을 안내한다.

- 물리: 같은 양·같은 햇빛을 유지하고 연속 해석해로 온도를 검산했다. 표지를 분자로 부르지 않는다. 서로 독립인 두 칸을 쓰므로 오른쪽을 바꾸어 왼쪽 온도 범위가 바뀐다고 주장하지 않는다.
- 교과서·오개념: p.108의 육풍 용어를 사용하고 중3 기압 층을 제외했다. p.99 아랄해 연결은 바다가 있던 오른쪽 칸의 일교차 비교로 고쳤다. 실제 지역 기후의 정량 예측이 아님을 밝혔다. 빈칸별 선택형만 채점한다.
- 사용성: 낮·밤 바로가기, 키보드 시각 조작, 현재 시각 자, 그래프 데이터 표를 제공한다. 같은 물질과 왼쪽/오른쪽이 뒤집힌 장면도 검사했다.
