# 바이메탈 스위치 설계 카드

비상교육 p.101–103, 107. 모형은 같은 두께의 두 금속 층으로 된 한쪽 고정 막대와 연동 접점이다. 핵심 조작은 위·아래 금속(알루미늄/놋쇠/구리/철)과 온도다. 장면·접점 방식·열원 위치는 접힌 더 해 보기에서 조작한다. 같은 금속도 허용한다.

막대 길이 25 mm, 전체 두께 0.4 mm. 두 층 탄성률은 같다고 이상화한다. α는 23/19/17/11×10⁻⁶/K, 기준 20 ℃. 곡률 κ=3(α위−α아래)ΔT/(2h), 작은 변형의 자유 끝 처짐 κL²/2를 쓴다. 위층이 더 길어지면 아래로 휘며 아래층이 오목하다. 그림의 길이 비율에 비해 휨 변화를 4배, 두께는 별도 확대한다. 떨어진 두 금속의 길이 변화 비교 막대는 선팽창 계산에 비례하고 모형 층으로 끈다.

꺼지는 스위치의 유연한 접점은 바이메탈의 작은 변형을 따라가다가 0.5 mm 이동 한계에서 떨어진다. 접점의 힘은 바이메탈 변형에 비해 작다고 가정한다. 켜지는 스위치는 0.5 mm 떨어진 접점에 도달하면 붙으며, 이후 끝이 접점에 막힌 모양과 자유로울 때 모양을 나누어 표시한다. 고정 접점이 끝을 누르는 변형은 균일 곡률 모형에 끝 힘으로 생기는 캔틸레버 변형을 중첩한다. 모든 금속을 같은 온도로 둬 열원의 위/아래 위치는 방향을 바꾸지 않는다. 전자의 이동 애니메이션은 넣지 않는다.

주전자: 물 1 kg, C=4187 J/K, 1500 W, 공기 20 ℃, 손실 5 W/K, 바이메탈 온도 응답 30초. 한 번 접점이 떨어지면 걸쇠로 꺼진 상태를 유지한다. 물 100 ℃에 도달하면 관찰을 끝내고 끓는 중·이 조합은 너무 늦게 꺼졌음을 표시한다. 끓는 물의 온도가 계속 오르지 않는다. 화재 경보기는 별도 열원인 수동 온도 장면에서 켜지는 접점을 관찰한다.

전기 장판: 열용량 300 J/K, 출력 180 W, 손실 3 W/K, 바이메탈 응답 5초. 접점 이동 기준 0.18 mm에서 끄고 0.10 mm에서 다시 켜는 이력 특성을 두어 접점 떨림을 피한다. 실제 제품의 안전 온도나 제조 설계를 예측하는 장치가 아니라 되풀이를 이해하는 열 모형이다. 주전자와 장판의 모형 상수·스위치 구조 차이를 명시한다. 고정 DT=0.05초, 재생 1초=30초, 15분 관찰.

미션은 가열·식힘, 주전자 끄기와 경보 켜기, 냉각 시 방향 예상, 온도만 바꾸는 변인, 같은 금속과 가열 위치 비교, 규칙 정리다. 선택형 확인 문제 3개. 수동·기기 장면의 관찰 온도만 ±0.2 ℃ 흔들려 기록되며 모형과 스위치 판정은 정확한 값을 쓴다. 계산식·처짐 mm·탄성률은 교사 설명에 둔다.

창의 장치는 두 금속을 따로 놓았을 때의 길이 변화 비교와 자유 휨 그림자다. 실제 붙어 있는 판이 층별로 따로 늘어나는 뜻이 아니며, 접점에 막힐 때도 변형하려는 경향이 있음을 설명한다. 열원 위치를 바꾸어도 방향이 유지되는 조작으로 한쪽에서 불을 대서 그쪽으로 휜다는 오개념을 검토한다.
