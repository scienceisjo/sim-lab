# 반응은 어떤 길을 거쳐 나올까? — 설계 카드

교육과정: 9과20-01, 9과20-02. 2022 개정 중학교 과학. 나선 교육과정 자료의 성취기준·해설·고려사항과 성취수준 C를 대조했다.

## 핵심 관계와 모형

감각기관의 자극은 신경을 통해 중추로 전달되고 반응 명령이 운동기관으로 전달된다.

조작: 반응 사례, 따라갈 신호. 관찰: 선택한 신호의 경로, 반응의 중추.

## 계산과 가정

대표적인 의식적 반응·척수 반사·동공 반사 경로. 회피 반사 신호는 뇌에도 전달되어 통증을 느끼므로 척수에서 끝난다고 설명하지 않는다. 실제 지연 시간은 임의로 정하지 않는다.

- 여러 뉴런이 관여하는 경로를 간단하게 펼쳤습니다. 반사 때도 감각 정보가 뇌에 전달됩니다.
- 그림의 색과 크기는 관계를 설명하기 위한 표현입니다.
- 모형은 선택한 조건만 다루므로 실제 현상의 모든 요인을 나타내지는 않습니다.

## 두 모드와 미션

모형 모드: 실험판, 핵심 조작, 장면/모형 설명 선택, 비교판. 학습 모드: 같은 모형 위에 기록·미션·선택형 확인 문제를 제공한다. 범주형 관찰이므로 가짜 수치·평균·그래프·측정 오차를 만들지 않는다.

- 조건을 두 가지 이상 바꾸어 현재 미션에서 새로 관찰·기록한다.
- 척수가 먼저 연결하는 반응: 뜨거운 것에서 손 떼기의 운동 명령을 기록하세요.
- 관찰 결과를 문장으로 설명한다.
- 확인 문제: 손을 먼저 뗀 뒤 통증을 느낄 수 있는 까닭은? / 밝은 빛에서 동공이 줄어드는 반사는?

## 창의 장치와 한계

같은 축척의 비교판으로 한 가지 조건만 바꾼 결과를 견줍니다.

여러 뉴런이 관여하는 경로를 간단하게 펼쳤습니다. 반사 때도 감각 정보가 뇌에 전달됩니다.

## 성취수준 C와 범위

- 9과20-01: 감각기관의 구조와 기능을 이해할 수 있다.
- 9과20-02: 뉴런과 신경계의 구조와 기능을 이해하고, 자극에 대한 반응이 일어나는 과정에 대한 모형을 이해할 수 있다.

이 페이지 하나로 해당 성취기준의 조사·토의·실물 실험 수행 전체를 평가하지 않는다. 전체 범위는 교육과정 대응표에서 구별한다.
