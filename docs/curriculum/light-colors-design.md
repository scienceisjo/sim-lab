# 같은 물체가 다른 색으로 보일까? — 설계 카드

교육과정: 9과10-03. 2022 개정 중학교 과학. 나선 교육과정 자료의 성취기준·해설·고려사항과 성취수준 C를 대조했다.

## 핵심 관계와 모형

빛의 합성과 물체가 반사하는 빛을 구별한다.

조작: 비추는 빛, 물체의 반사 특성. 관찰: 눈에 들어오는 빛.

## 계산과 가정

세 RGB 성분을 0/1로 갖는 이상 필터·반사체 모형. 반사 성분=입사 성분×반사율. 실제 색 지각과 연속 스펙트럼·조명 세기는 생략한다.

- 실제 물체의 반사율은 파장별로 연속적입니다. 이 모형은 세 성분을 완전히 반사하거나 흡수하는 이상적 경우입니다.
- 그림의 색과 크기는 관계를 설명하기 위한 표현입니다.
- 모형은 선택한 조건만 다루므로 실제 현상의 모든 요인을 나타내지는 않습니다.

## 두 모드와 미션

모형 모드: 실험판, 핵심 조작, 장면/모형 설명 선택, 비교판. 학습 모드: 같은 모형 위에 기록·미션·선택형 확인 문제를 제공한다. 범주형 관찰이므로 가짜 수치·평균·그래프·측정 오차를 만들지 않는다.

- 조건을 두 가지 이상 바꾸어 현재 미션에서 새로 관찰·기록한다.
- 빨간 물체를 초록빛으로 보기: 초록빛과 빨간 물체를 선택해 결과를 기록하세요.
- 관찰 결과를 문장으로 설명한다.
- 확인 문제: 파란빛만 비춘 이상적인 빨간 물체는? / 화면의 RGB 빛을 모두 합치면?

## 창의 장치와 한계

같은 축척의 비교판으로 한 가지 조건만 바꾼 결과를 견줍니다.

실제 물체의 반사율은 파장별로 연속적입니다. 이 모형은 세 성분을 완전히 반사하거나 흡수하는 이상적 경우입니다.

## 성취수준 C와 범위

- 9과10-03: 물체의 색이 물체에서 반사된 빛들의 합성으로 만들어짐을 말할 수 있고, 여러 가지 영상 장치들의 빛의 삼원색 관찰에 적극적으로 참여할 수 있다.

이 페이지 하나로 해당 성취기준의 조사·토의·실물 실험 수행 전체를 평가하지 않는다. 전체 범위는 교육과정 대응표에서 구별한다.
