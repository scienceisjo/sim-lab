# 반응할 때 주변은 따뜻해질까? — 설계 카드

교육과정: 9과16-06. 2022 개정 중학교 과학. 나선 교육과정 자료의 성취기준·해설·고려사항과 성취수준 C를 대조했다.

## 핵심 관계와 모형

발열 반응은 주변으로 에너지를 전달하고 흡열 반응은 주변에서 에너지를 받는다.

조작: 반응의 종류, 반응한 양의 배수, 주변 물의 질량. 관찰: 주변 물의 온도, 주변이 받은 열.

## 계산과 가정

실제 반응물 데이터가 아닌 명시적 열량계 모형. 반응 1단위당 주변으로 ±420 J, 물 비열 4.2 J/(g·℃), 외부 열손실 없음. ΔT=Q/(mc). 물의 상태 변화 없음.

- 특정 화학 물질의 실제 반응열이 아닙니다. 반응과 주변 사이 에너지 이동을 비교하는 열량계 모형입니다.
- 그림의 색과 크기는 관계를 설명하기 위한 표현입니다.
- 모형은 선택한 조건만 다루므로 실제 현상의 모든 요인을 나타내지는 않습니다.

## 두 모드와 미션

모형 모드: 실험판, 핵심 조작, 장면/모형 설명 선택, 비교판. 학습 모드: 같은 모형 위에 기록·미션·선택형 확인 문제를 제공한다. 측정 오차는 표시와 기록에만 더하며 계산과 모형 그림에는 적용하지 않는다.

- 조건을 두 가지 이상 바꾸어 현재 미션에서 새로 관찰·기록한다.
- 변인 설계: 첫 번째 조건만 바꾸고 나머지를 고정하여 두 조건 이상 기록한다.
- 주변에서 열을 받는 반응: 흡열 반응 2배, 물 100 g에서 세 번 기록하고 주변 온도를 살펴보세요.
- 관찰 결과를 문장으로 설명한다.
- 확인 문제: 흡열 반응에서 주변 물이 차가워진 까닭은? / 온도 변화가 작으면 항상 반응열도 작나요?
