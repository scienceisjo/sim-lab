# 흑점이 많으면 지구에는 꼭 문제가 생길까? — 설계 카드

교육과정: 9과07-02. 2022 개정 중학교 과학. 나선 교육과정 자료의 성취기준·해설·고려사항과 성취수준 C를 대조했다.

## 핵심 관계와 모형

흑점은 태양 활동의 지표이며 지구 영향은 분출 방향과 여러 조건에 따라 달라진다.

조작: 비교할 태양, 분출 방향. 관찰: 흑점 관찰, 지구 영향의 해석.

## 계산과 가정

대표적 두 상태의 개념 비교. 실제 연도·흑점 관측 수·재해 확률은 생성하지 않는다. 태양 활동은 약11년 주기 경향이 있지만 주기와 강도는 일정하지 않다. 흑점은 주변보다 차가워 어둡게 보이는 영역.

- 특정 날짜의 태양 관측이나 우주 날씨 예보가 아닙니다. 지구 방향이라고 장애가 반드시 일어나는 것은 아닙니다.
- 그림의 색과 크기는 관계를 설명하기 위한 표현입니다.
- 모형은 선택한 조건만 다루므로 실제 현상의 모든 요인을 나타내지는 않습니다.

## 두 모드와 미션

모형 모드: 실험판, 핵심 조작, 장면/모형 설명 선택, 비교판. 학습 모드: 같은 모형 위에 기록·미션·선택형 확인 문제를 제공한다. 범주형 관찰이므로 가짜 수치·평균·그래프·측정 오차를 만들지 않는다.

- 조건을 두 가지 이상 바꾸어 현재 미션에서 새로 관찰·기록한다.
- 활동이 강해도 방향은 다를 수 있음: 활동이 강한 태양에서 지구와 다른 방향의 분출을 기록하세요.
- 관찰 결과를 문장으로 설명한다.
- 확인 문제: 흑점은 빛을 전혀 내지 않는 구멍인가요? / 태양 활동 주기를 어떻게 이해하나요?
