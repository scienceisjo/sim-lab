# 전류는 전구를 지나면 줄어들까? — 설계 카드

교육과정: 9과14-02, 9과14-03. 2022 개정 중학교 과학. 나선 교육과정 자료의 성취기준·해설·고려사항과 성취수준 C를 대조했다.

## 핵심 관계와 모형

전압과 저항이 전류를 정하며 전류는 직렬 회로에서 이어지고 병렬 회로의 가지에서 나뉜다.

조작: 전지 전압, 각 저항, 연결. 관찰: 전지 쪽 전류, 저항 하나의 전류, 에너지 전환.

## 계산과 가정

이상 전지·도선, 일정 저항. 하나 R, 직렬 2R, 병렬 R/2로 내부 계산. 합성 저항 공식과 소비전력 정량 문항은 제시하지 않는다. 점은 관습적 전류 방향의 표지이며 전자의 실제 속도가 아니다.

- 저항은 온도에 따라 바뀌지 않는다고 가정합니다. 전구의 밝기와 저항 변화를 그대로 재현하지 않습니다.
- 그림의 색과 크기는 관계를 설명하기 위한 표현입니다.
- 모형은 선택한 조건만 다루므로 실제 현상의 모든 요인을 나타내지는 않습니다.

## 두 모드와 미션

모형 모드: 실험판, 핵심 조작, 장면/모형 설명 선택, 비교판. 학습 모드: 같은 모형 위에 기록·미션·선택형 확인 문제를 제공한다. 측정 오차는 표시와 기록에만 더하며 계산과 모형 그림에는 적용하지 않는다.

- 조건을 두 가지 이상 바꾸어 현재 미션에서 새로 관찰·기록한다.
- 변인 설계: 첫 번째 조건만 바꾸고 나머지를 고정하여 두 조건 이상 기록한다.
- 가지와 전체 비교하기: 3 V, 각 10 Ω, 병렬연결에서 세 번 기록하세요.
- 관찰 결과를 문장으로 설명한다.
- 확인 문제: 저항에서 소비되는 것은? / 전압을 같게 두고 저항을 크게 하면?

## 성취수준 C와 범위

- 9과14-02: 전기 회로에서 전류의 방향과 전자의 이동 방향을 비교하여 말할 수 있다.
- 9과14-03: 저항의 직렬연결과 병렬연결의 특징을 알고, 일상생활에서 전기 제품들의 소비 전력을 전기 에너지 전환과 관련지어 조사할 수 있으며, 전기를 효율적으로 사용하려는 태도를 가진다.

이 페이지 하나로 해당 성취기준의 조사·토의·실물 실험 수행 전체를 평가하지 않는다. 전체 범위는 교육과정 대응표에서 구별한다.
