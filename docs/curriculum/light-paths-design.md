# 빛은 경계에서 어디로 갈까? — 설계 카드

교육과정: 9과10-01. 2022 개정 중학교 과학. 나선 교육과정 자료의 성취기준·해설·고려사항과 성취수준 C를 대조했다.

## 핵심 관계와 모형

빛의 반사각은 입사각과 같고, 물질 경계를 통과할 때 방향이 바뀔 수 있다.

조작: 법선에서 잰 입사각, 경계. 관찰: 반사각, 굴절각 또는 거울의 반사각.

## 계산과 가정

반사각=입사각. 공기 n=1, 물 n=1.333, 유리 n=1.5의 스넬 법칙으로 광선 계산. 정량 굴절 법칙은 교사용 내부 계산에만 둔다. 분산·편광·반사율은 생략.

- 빛의 길은 선으로 표시한 모형입니다. 선의 굵기는 밝기가 아니며 물질 속 속력의 정량 계산은 다루지 않습니다.
- 그림의 색과 크기는 관계를 설명하기 위한 표현입니다.
- 모형은 선택한 조건만 다루므로 실제 현상의 모든 요인을 나타내지는 않습니다.

## 두 모드와 미션

모형 모드: 실험판, 핵심 조작, 장면/모형 설명 선택, 비교판. 학습 모드: 같은 모형 위에 기록·미션·선택형 확인 문제를 제공한다. 측정 오차는 표시와 기록에만 더하며 계산과 모형 그림에는 적용하지 않는다.

- 조건을 두 가지 이상 바꾸어 현재 미션에서 새로 관찰·기록한다.
- 변인 설계: 첫 번째 조건만 바꾸고 나머지를 고정하여 두 조건 이상 기록한다.
- 수직으로 입사시키기: 공기에서 물로 들어가는 입사각을 0°로 만들고 세 번 기록하세요.
- 관찰 결과를 문장으로 설명한다.
- 확인 문제: 입사각은 어디에서 재나요? / 물체를 보려면 어떤 경로가 필요한가요?
