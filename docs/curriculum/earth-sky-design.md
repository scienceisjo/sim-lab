# 지구가 움직이면 하늘은 어떻게 보일까? — 설계 카드

교육과정: 9과07-03. 2022 개정 중학교 과학. 나선 교육과정 자료의 성취기준·해설·고려사항과 성취수준 C를 대조했다.

## 핵심 관계와 모형

지구 자전의 반대 방향으로 하늘이 겉보기 운동하며 공전하면 한밤중에 보는 먼 배경 방향이 달라진다.

조작: 지구의 자전 각, 지구의 공전 위치. 관찰: 별의 겉보기 회전각, 한밤중 배경 방향.

## 계산과 가정

북극 위에서 내려다본 2D 좌표. 공전 위치 e=(cosθ,sinθ); 한밤중 바깥 방향은 태양→지구 방향 θ. 자전+φ에 대해 관측자 좌표의 먼별각은 −φ. 360°는 같은 방향. 위도별 일주운동·황도좌표·계절 온도는 다루지 않는다.

- 북극 위에서 본 공간 모형입니다. 원 밖의 별 표지는 실제 별자리 모양이나 거리를 나타내지 않습니다.
- 그림의 색과 크기는 관계를 설명하기 위한 표현입니다.
- 모형은 선택한 조건만 다루므로 실제 현상의 모든 요인을 나타내지는 않습니다.

모형 모드: 실험판, 핵심 조작, 장면/모형 설명 선택, 비교판. 학습 모드: 같은 모형 위에 기록·미션·선택형 확인 문제를 제공한다. 측정 오차는 표시와 기록에만 더하며 계산과 모형 그림에는 적용하지 않는다.

- 조건을 두 가지 이상 바꾸어 현재 미션에서 새로 관찰·기록한다.
