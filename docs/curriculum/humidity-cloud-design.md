# 수증기가 늘지 않아도 습해질까? — 설계 카드

교육과정: 9과17-03. 2022 개정 중학교 과학. 나선 교육과정 자료의 성취기준·해설·고려사항과 성취수준 C를 대조했다.

## 핵심 관계와 모형

기온이 내려가면 포화 수증기압이 낮아져 상대습도가 커지며 포화 이후 응결할 수 있다.

조작: 기온, 냉각 전 수증기압. 관찰: 상대습도, 포화 수증기압, 응결 여부.

## 계산과 가정

0~30 ℃에서 Bolton형 근사 e_s=6.112exp(17.67T/(T+243.5)) hPa. 일정 압력에서 초기 혼합비를 정한 공기를 냉각. 포화 이전 수증기압 e0, 이후 응결평형 e=e_s. RH=100e/e_s. 이 모델은 단열상승의 높이·잠열을 정량 계산하지 않는다.

- 응결핵이 있고 충분히 기다린 평형 모형입니다. 구름은 물방울이나 얼음 알갱이이며 눈에 안 보이는 수증기 자체가 아닙니다.
- 그림의 색과 크기는 관계를 설명하기 위한 표현입니다.
- 모형은 선택한 조건만 다루므로 실제 현상의 모든 요인을 나타내지는 않습니다.

## 두 모드와 미션

모형 모드: 실험판, 핵심 조작, 장면/모형 설명 선택, 비교판. 학습 모드: 같은 모형 위에 기록·미션·선택형 확인 문제를 제공한다. 측정 오차는 표시와 기록에만 더하며 계산과 모형 그림에는 적용하지 않는다.

- 조건을 두 가지 이상 바꾸어 현재 미션에서 새로 관찰·기록한다.
- 변인 설계: 첫 번째 조건만 바꾸고 나머지를 고정하여 두 조건 이상 기록한다.
- 냉각으로 응결 만들기: 냉각 전 수증기압 12 hPa, 기온 0 ℃에서 세 번 기록하세요.
- 관찰 결과를 문장으로 설명한다.
- 확인 문제: 구름이 생기는 대표 과정은? / 상대습도 100%이면 반드시 비가 오나요?
