# 온도색과 전도·대류 재설계 검토

2026-09-27 사용자 피드백에 따라 온도 관련 15개 실험실을 수정했다. 전도·대류의 계산과 확대 표현을 재설계했으며, 그 밖의 실험실은 기존 수치 법칙을 유지하면서 온도색과 범례를 연결했다. 설계 기준은 [설계 카드](thermal-remodel-design.md)를 따른다.

## 학생이 보는 변화

- 전도·대류·복사: 세 방식 함께 보기 / 전도 입자 확대 / 대류 물속 확대 / 복사 경로의 네 보기. 불·물 흐름·가림판 조작과 학습 모드의 6개 미션·3개 문제는 유지한다. 물의 최고 온도도 별도로 표시한다.
- 전도 확대창: 같은 사인파를 순서대로 그리던 표현을 제거했다. 제자리 부근에서 두 방향으로 움직이는 입자가 이웃과 힘을 주고받는다. 빈 원으로 평형 위치를 표시하고 입자 하나에 테두리를 둘러, 입자가 끝까지 이동하는 것이 아님을 살펴볼 수 있다.
- 대류 확대창: 216칸의 온도장을 계산하고 같은 속도장으로 물 덩어리 표지를 이동시킨다. 가운데 가열 → 상승 → 상부 이동 → 양옆 하강을 온도색과 이동 자취로 연결한다. 화면의 온도장은 보간해 매끄럽게 보여 주며 표시색 때문에 물결이 생기지는 않는다.
- 온도색: 동일 온도에는 동일 색을 사용한다. 입자 하나의 순간 운동을 온도라고 부르지 않고, 해당 부분의 평균 온도를 색으로 표시한다. 크기·개수는 바꾸지 않는다. 색 눈금, 실제 색이 아니라는 설명, 기존 수치 읽기를 함께 제공한다.
- 열평형의 60 ℃ 물은 주황, 5 ℃ 물은 파랑이며 평형에 가까워지면 같은 색으로 가까워진다. 액체 초기 입자 배열을 불규칙하게 만들어 결정 격자로 오해하지 않게 했다. 열팽창의 액체 창에도 같은 원칙을 적용했다.
- 상태 변화는 같은 온도에서 진행되는 동안 온도색이 유지된다. 고체·액체의 구별은 무늬·비율·설명을 사용한다. 기체라는 이유로 무조건 뜨겁게 표시하지 않는다.

두 모드는 같은 계산과 모형을 쓴다. 학습 모드만 기록·미션·문제·측정 흔들림을 추가한다. 온도색과 운동에는 측정 오차를 넣지 않는다. 이 변경으로 계산이 바뀐 전도·대류·복사는 실험실과 기록장 버전을 2로 올려 이전 조건의 기록을 새 결과와 섞지 않는다.

## 계산과 단순화

고체 확대창은 이웃 조화 결합과 평형점 복원력을 두 방향으로 계산하고 Velocity Verlet로 1/720초씩 적분한다. 국소 Langevin 열저장고를 거시 모형 온도에 연결한다. 움직임은 확대·감속한 설명 모형이며 실제 금속의 전도율을 이 작은 격자로 예측하지 않는다. 금속의 자유 전자도 전도에 기여하지만 이 확대창에는 생략한다.

손잡이는 열용량 합 50 J/K의 12부분으로 나누고 이웃 열전달 계수는 7.2 W/K로 둔다. 입자 확대창의 색은 해당 부분 온도에서 읽는다. 냄비 180 J/K, 물 4180 J/K, 불 약/강 150/300 W이며, 예전 두 덩어리 물 모형의 300/600 W와 다르다.

물은 24×16 cm 단면, 부피 1 L, 18×12 유한체적 격자다. 각 면을 통과하는 물과 열을 이웃에서 정확히 반대 부호로 주고받는다. 열전도율 0.6 W/(m K), 가운데 아래 면의 총 접촉 계수 100 W/K를 사용한다. 가운데 상승·양옆 하강의 발산 없는 유선함수와 부력·저항 평균 속도 방정식을 결합했다. 실제 냄비의 모든 소용돌이나 전체 Navier–Stokes 방정식을 푼 것은 아니다. ‘물 흐름 막기’에서는 이동항만 0으로 하고 전도를 남긴다. 외부 공급과 공기 손실을 포함하여 에너지 장부를 대조한다.

물의 어느 부분이든 95 ℃에 닿으면 끓기 전에 멈춘다. 평균만 검사하면 바닥 일부의 과열을 놓칠 수 있어 최고 온도와 종료 메시지를 추가했다. 복사 교환은 기존 절대온도 네제곱 법칙·가림판 재방출을 유지한다. 복사 화살표 길이는 경로 표시이며 방출 크기 비교 막대와 구별한다.

15개 실험실의 미션 86개와 선택형 확인 문제 41개를 실제 조작으로 통과했다. 네 화면 크기의 회귀 검사와 최종 갤러리·탐구 지도 링크 검사를 통과했으며, 최종 15개 페이지에서 자바스크립트 오류와 자료 요청 실패가 없었다.

- tests/thermal-edge.cjs: 전체 장치의 에너지 보존, 국소 최고 온도에서 정지, 시간 간격 수렴.
- tests/heat-three-ways.cjs, conduction-camera.cjs, heat-equilibrium.cjs, thermal-expansion.cjs, syringe-particles.cjs, state-change-particles.cjs, phase-heat-curves.cjs, specific-heat.cjs, bimetal-switch.cjs, sea-land-breeze.cjs, cookware-test-bench.cjs: 기존 수치·실제 클릭 미션·문제·네 화면 회귀 검사.

## 반박 검토와 남은 범위

동일 개발자가 과학·오개념·사용성 관점을 나누어 자체 검토했다. 독립 외부 검토를 받았다고 주장하지 않는다.

과학: 이웃 상호작용 없이 순서만 늦춘 진동 그림, 회색 점의 타원 순환, 평균 온도만 보는 종료 조건을 수정했다. 대류 모형에서 흐름 막기를 했을 때 국소 가열이 빨라지는 것을 확인하고 가열 출력을 조정하여 비교 미션의 관찰 시간을 확보했다.

오개념: 순간 속도=입자 하나의 온도, 물 덩어리=분자, 고체 입자가 통째로 이동함, 액체의 규칙적 격자, 상태가 다르면 반드시 온도가 다름을 구별했다. 범례·색·입자 크기·교사 설명을 함께 확인했다. 온도장을 계산하지 않는 해풍·육풍의 공기 표지에는 가상의 온도색을 붙이지 않았다. 그 실험실의 지표면에는 실제 모형 온도색을 쓴다.

사용성: 상태가 보이는 관찰 창 단추, 작은 화면의 별도 확대 보기, 간단한 온도색 안내와 접기 설명을 제공한다. 모바일 범례 겹침을 수정했다. 새 설명 접기창 때문에 점검 도구가 첫 summary를 누르던 두 검사를 명시적 단추 이름으로 고쳤다. 감소된 움직임을 요청한 브라우저에서는 새 입자 확대창의 진동을 정지한다.

남은 한계: 유체의 복잡한 3차원 난류와 금속 자유 전자의 동역학은 다루지 않는다. 온도 미정인 분류·경로 모형을 임의의 수치 시뮬레이션으로 바꾸지 않았다. 모든 63개 실험실을 새로 만들었다는 뜻이 아니라 온도 관련 15개와 전도·대류 핵심 모형의 개선이다.
