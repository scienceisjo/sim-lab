# 교육과정 기반 실험실 대응표

2026-09-27 사용자 요청: 교과서 활동을 복제하지 않고 나선 교육과정 자료를 기준으로 중학교 핵심 개념 모형을 구성한다. 기존 18개 실험실과 신규 45개 모형·관찰 실험실을 교사 검토용 curriculum/에 모았다. 공개 갤러리 sims.js는 변경하지 않았다.

**대응은 해당 성취기준의 일부 개념을 탐색한다는 뜻이다. 이 모형들만으로 성취기준 전체를 달성·평가했다는 뜻이 아니다.** 특히 조사·발표·토의·실천과 실물 실험 설계·수행은 별도 활동이다.

## 모형만으로 다루지 않는 부분

- 지속가능한 삶·미래 직업·우주탐사의 사회적 영향: 실제 자료 조사·논증·실천이 핵심이다. 임의 수치의 가짜 예측 모형을 만들지 않았다.
- 재해·재난: 지권과 날씨 모형을 원리 학습에 연결하되 실제 재난 발생·피해·안전을 예측하거나 보장하지 않는다. 공식 자료를 이용한 별도 조사와 대응 설계가 필요하다.
- 생물다양성 보전·수자원 가치: 개념 모형의 적용 질문으로 연결하며 실제 보전 행동의 효과를 임의 확률로 수치화하지 않는다.
- 기관·세포 구조, 분류, 암석 순환: 관찰형 모형이다. 범주·경로에 수치 오차나 평균을 덧붙이지 않는다.
