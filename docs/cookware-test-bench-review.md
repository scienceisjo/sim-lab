# 조리 도구 재료 비교·열변색 설계 검토 보고

비상교육 p.95, 97–99, 103–105, 109. 모형 모드는 불판·받침·손잡이 성질을 바꾸고, 부품별로 따로 시험한 결과를 비교한다. 더 해 보기에서 받침 냉각 시간과 열변색 기준을 고른다. 학습 모드는 6개 미션, 온도 반복 측정·평균·그래프·표·CSV와 확인 문제 3개를 더한다. 실제 음식을 익히거나 조리 도구 안전성을 판정하는 시뮬레이션은 아니다.

## 계산과 검산

각 부품 시험 시료 50 g, 상대 비열 철 0.107·알루미늄 0.214·물 1에 4187 J/(kg K)를 곱한다. 불판은 20 ℃에서 20 W로 60초 가열하며 주변 손실 0.15 W/K의 해석해를 사용한다. 받침은 같은 60 ℃에서 같은 손실 조건으로 식힌다. 용기 열용량은 생략하고 시료 안 온도는 고르다고 가정한다. 길이 비교는 별도 시험으로 처음 20 cm, 두 재료 모두 20→80 ℃이며 α철=11, α알루미늄=23×10⁻⁶/K다.

## 미션·창의 장치·반박 검토

실제 클릭·키보드로 6/6: 세 부품 바꾸기, 공개한 비교 목적에 맞는 조합, 받침만 바꾸는 변인, 같은 처음 온도의 냉각, 기준을 가로지르는 열변색 관찰, 부품별 성질 정리. 확인 문제 3/3. 잘못된 손잡이 선택과 같은 조건 반복으로 변인 완료가 되지 않음을 확인했다. 서술형 자동 채점은 없다.

창의 장치는 같은 온도 변화에서 늘어난 길이 막대와 받침의 열변색 표지다. 막대는 실제 선팽창값에 비례한다. 표지는 계산 온도에 반응하며 모형 층과 함께 끈다. 온도는 눈에 보이는 색·글자로 바뀌지만 색이 안전을 보장하거나 액체 양을 재는 것은 아니다. 물 받침의 색과 측정 온도가 기준 근처에서 조금 다를 수 있는 이유도 측정 오차로 안내한다.

- 물리: 끝을 이은 부품의 팽창 차를 바이메탈 휨으로 그리는 이전 설계를 제거했다. 모든 부품이 한 시각의 같은 온도인 것처럼 섞지 않고 각 시험 조건을 명시했다. 비열과 전도를 구별한다.
- 교과서·오개념: 철·알루미늄만 불판 후보로 두고, 내열 유리를 최고 불판으로 추천하지 않는다. 교과서 성질에 맞는 철 불판·물 받침·전도가 작은 손잡이는 제시한 비교 목적을 충족하지만 보편적인 최고 제품이라는 결론은 내리지 않는다. p.109 열변색 설계를 가정값과 함께 포함했다.
- 사용성: 핵심 세 선택과 접힌 추가 조건을 구분했다. 색과 글자를 함께 표시하고 그래프 데이터 표·키보드 조작을 제공한다. 실제 가열 재생을 흉내 내지 않고 정해진 시간의 비교 상태를 즉시 보여 준다.
