# 세 상태와 상태 변화 검토 보고

비상교육 p.121–134. 모형 모드는 세 상태 압축, 여섯 상태 변화, 아세톤 기화 전후 질량, 차가운 시계 접시의 물 확인을 조작한다. 학습 모드는 7개 미션, 세 종류의 기록장·평균·그래프·CSV와 확인 문제 3개를 더한다.

## 계산·손계산 대조

주사기는 같은 온도에서 천천히 누르는 이상 기체와 비압축성 고체·액체 근사다. 처음 20 mL, 누르는 압력 비 1~2. 상태 변화는 변한 질량 비율을 사용자가 지정하는 관찰 단면이며, 변화 속도를 예측하지 않는다. 대표 입자 40개의 수·종류·질량은 보존한다. 물질 1 g의 부피는 두 상의 부피를 질량 비율로 합한다. 기체 부피는 이상 기체 근사이며 실제 포화 증기값과 차이가 있을 수 있다.

| 항목 | 독립 계산 | 엔진 |
|---|---:|---:|
| 공기, 누르는 압력 비 1→2 | 20→10 mL | 일치 |
| 고체·액체, 같은 압력 변화 | 20→20 mL | 일치 |
| 물 1 g, 0 ℃ | 1/0.99987=1.000130 mL | 일치 |
| 얼음 1 g, 0 ℃ | 1/0.917=1.090513 mL | 일치 |
| 수증기 1 g, 100 ℃·1기압 | nRT/P=1699.651971 mL | 일치 |
| CO₂ 1 g, −78.5 ℃·1기압 | nRT/P=362.932238 mL | 일치 |
| 아세톤 주머니, 기화 전후 | 1→712.034966 mL | 일치 |
| 기화 뒤 주머니 안팎 압력 | 52.915133 kPa | 일치 |
| 전체 장치 질량 | 266.1→266.1 g | 일치 |

두 모드에서 압축 30조건과 상태 변화 492조건을 독립식과 대조했다. 장치 4조건과 측정 흔들림 끝값 4조건도 확인했다. 아세톤 0.79 g, 분자량 58.0791, 바깥 용적 2 L, 처음 공기 20 ℃·30 kPa, 나중 60 ℃이다. 보존한 바깥 공기와 아세톤의 몰수 비로 주머니 부피를 구한다. 학습 저울만 ±0.04 g이며 반올림까지 포함한 기록 허용 범위를 쓴다.

액체·기체의 표시층은 같은 질량의 탄성 원판 충돌·벽 반사, DT=1/120초다. 실제 분자 간 인력·점성을 재현하는 액체 모형이라고 주장하지 않는다. 20/40개·두 영역 크기에서 60초를 계산하여 운동에너지 보존과 경계 안 위치를 검사했다. 고체는 제자리 진동이다. 표시층의 임의 운동으로 상태를 판정하지 않는다.

물의 밀도는 [USGS 자료](https://www.usgs.gov/water-science-school/science/water-density), 얼음 약 0.917은 [NIST 밀도 측정](https://nvlpubs.nist.gov/nistpubs/jres/38/jresv38n6p583_A1b.pdf), 드라이아이스 약 1.56은 [Airgas 물성](https://www.airgas.com/msds/001091.pdf)을 확인했다. [NIST 아세톤 Antoine 계수](https://webbook.nist.gov/cgi/inchi?ID=C67641&Mask=4&Plot=on&Type=ANTOINE)로 구한 포화 증기압 20 ℃ 24.604 kPa·60 ℃ 114.963 kPa와 비교하여 처음 액체/나중 기체라는 끝 상태 가정도 검사했다.

## 미션·화면·반박 검토

실제 클릭·키보드로 7/7: 세 상태 압축, 누르는 정도의 변인, 드라이아이스 예상, 여섯 변화 수집, 기화 전후 질량, 응축수 확인, 개념 정리. 확인 문제 3/3. 예상 전 기록, 중탕 중·물기 제거 전 측정, 지시약만 먼저 누르기, 같은 조건 반복만으로 변인 통과하기는 막았다.

창의 장치는 두 상태에 나뉜 입자 수 장부와 같은 눈금의 부피 막대다. 합계 40개가 유지되는 동안 부피가 달라짐을 연결한다. 두 입자 창은 서로 다른 확대율의 도해다. 막대는 계산 부피에 비례하지만 입자 창의 넓이를 실제 부피처럼 읽으면 안 된다. 물의 응고는 성긴 배열과 증가하는 부피를 함께 보여 준다.

- 물리: 미보정 LJ 모형의 액체 판정과 화면 끝에서 기체를 강제로 압축하는 설계를 제거했다. 움직임 도해에서 입자가 겹치는 문제는 탄성 충돌 표시층으로 고쳤다. 동일한 물질의 색·입자 크기는 유지한다. 단단한 장치 전체를 재어 주머니가 부풀 때의 외부 부력 변화를 섞지 않는다.
- 교과서·오개념: 고체도 진동한다. 물이 얼면 부피가 증가한다. CO₂는 1기압에서 액체를 거치지 않는다. 수증기·CO₂ 기체는 보이지 않고 흰 김은 액체다. 물방울 한 개와 물 입자 한 개를 구별한다. 열에너지 곡선은 다음 실험실로 분리했다.
- 사용성: 장면별 조작만 표시한다. 중탕 → 꺼내기 → 닦기 순서를 조작으로 확인한다. 측정·기록 종류별 단위를 분리했다. 키보드 슬라이더와 그래프 데이터 표를 제공한다. 실제 응축 속도·지시약 반응량을 계산한다고 주장하지 않는다.
