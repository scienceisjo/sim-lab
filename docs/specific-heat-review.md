# 비열 검토 보고

비상교육 p.96–99, 104, 107. 모형 모드에서는 가열/냉각과 두 시료를 조작하고, 온도 곡선과 공급 열 막대를 비교한다. 양 조작은 접힌 더 해 보기에 둔다. 학습 모드에는 미션 6개, 반복 측정·평균·표·그래프·CSV와 확인 문제 3개가 있다.

## 계산·가정과 검산

상대 비열은 물 1, 콩기름 0.47, 에탄올 0.568, 알루미늄 0.214, 모래 0.191, 철 0.107이며 4187 J/(kg K)를 곱해 내부 단위로 바꾼다. C=mc, 출력 20 W, 주변 20 ℃, 손실 계수 0.15 W/K. 가열 T=20+(20/0.15)(1−exp(−0.15t/C)), 냉각 T=20+40exp(−0.15t/C)를 0.1초 간격으로 계산한다. 재생 1초는 실험 30초다. 용기 열용량은 생략하고 각 시료 내부 온도는 고르다고 가정한다.

두 모드×6물질×3가지 양×가열/냉각 72조건에서 해석해 및 두 모드 결과가 일치했다. 80 ℃, 에탄올 70 ℃에 한 시료가 도달하면 두 장치를 함께 멈춘다. 위 300초 결과는 물·콩기름에만 해당하며 고체를 300초까지 강제로 가열하지 않는다. 이는 교과서 실측 온도가 아니라 명시한 조건의 모형값이다. 학습 기록에만 ±0.2 ℃ 오차 후 소수 첫째 자리 반올림을 넣는다.

## 미션·창의 장치

실제 UI 조작으로 6/6 완료: 가열/냉각 탐색, 물·콩기름 비교, 같은 양의 알루미늄·물 예상, 물질만 바꾸는 변인 설계, 여섯 물질 비열 순서 일괄 판정, 프라이팬·찜질 팩 적용. 확인 문제 3/3. 예상 전 재생, 관찰 없이 순서 찍기, 같은 조건 반복으로 변인 완료를 막았다. 가까운 모래·알루미늄은 직접 비교 기록이 있어야 순서 미션을 통과한다.

창의 장치는 실제 공급 열 P×t에 비례하는 막대와 온도 곡선이다. 공급 열과 시료에 남은 열을 구별하며 냉각에서는 공급 열 막대를 숨긴다. 입자 크기나 속도를 비열 원인의 대용으로 쓰지 않는다. 고체에는 센서를 꽂는 그림 대신 모형 온도를 표시하고, 같은 g의 액체도 높이가 다를 수 있게 그린다.

## 화면과 세 관점 반박 검토

1920×1080·1366×768·1024×768·390×844에서 두 모드×가열/냉각/고체 총 24장. `specific-heat-<model|learn>-<heat|cool|solid>-<폭>x<높이>.png`. 재현 도구 `tests/specific-heat.cjs`. 가로 넘침·콘솔 오류 없음.

- 물리: 개별 상한 정지 때문에 공급 열 비교가 깨지는 이전 설계를 두 장치 동시 종료로 고쳤다. 냉각 손실이 같다는 표현을 제거했다.
- 교과서·오개념: 질량을 학생 화면에서 양(g)으로 표기하고 실제 액체 높이를 구별했다. 생활 활용 문항과 모래·알루미늄 직접 비교를 추가했다. 에탄올의 실물 가열 금지 안내는 선택 시 나타난다.
- 사용성: 작은 화면에서 온도 숫자를 가리던 가열판 겹침을 수정했다. 키보드로 선택·재생·기록·순서 응답이 가능하며 그래프 데이터 표를 제공한다.
