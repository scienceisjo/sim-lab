# 1단계 설계 카드 — 두 모드와 학습 활동

범위: 힘의 표현과 평형(비상교육 중1 pp.157–161, [9과05-01]), 마찰력(pp.170–171, [9과05-02]). 2단계 실험실은 만들지 않는다.

## 모형과 계산
- 모형은 물체에 작용하는 힘 화살표다. 실제 모습은 같은 물체·줄·센서 장면에서 화살표와 설명 층을 끈 모습이며 사진이나 실제 실험이 아님을 밝힌다.
- 두 모드가 기존 고정 시간 간격 계산을 공유한다. 합력의 부호 있는 합, 질량 5 kg, 마찰 없는 가정, 마찰력의 정지/미끄럼 계산은 유지한다.
- 무작위 측정 흔들림은 학습 패널과 기록값에만 적용한다. 힘의 평형과 운동, 그림의 길이, 통과 판정에는 넣지 않는다. 설정값과 모형값은 구별해서 표시한다.
- 힘의 표현은 두 센서 각각 ±0.2 N, 마찰력은 ±0.08 N의 독립 균등 흔들림을 가정한다. 영점인 센서는 0으로 둔다. 여러 번 재기와 조건별 평균을 제공하되 평균이 반드시 참값과 같아진다고 가르치지 않는다.

## 조작과 활동
- 모형 모드: 핵심 조건, 재생, 실제 모습/모형 전환, 측정값. 미션·기록·문제는 숨기고 기록과 진도도 쌓지 않는다.
- 학습 모드: 기존 6미션을 유지하고 변인 설계 미션 1개씩 추가한다. 설계 제출 이후 현재 미션에서 얻은 기록만 증거로 삼고 바꿀 변인의 서로 다른 값과 통제 변인의 일치를 검사한다.
- 기록장 공통 API: 열 정의, 버전별 저장, 표·조건별 평균·선택 축 산점도·CSV, 그래프 데이터 표. 마찰의 자체 저장소는 공통 기록장으로 이관하되 이전 기록은 미션 증거로 인정하지 않는다.
- 힘의 표현에서는 정지 상태에서 두 센서 값을 기록한다. 합력은 측정한 두 힘의 부호 있는 합이다. 마찰은 작은 간격으로 당겨 처음 미끄러진 순간을 한 행으로 자동 기록하고, 되감아 같은 조건에서 다시 잰다.
- 확인 문제 3개씩: 진단·적용·새 상황. 선택형만 확인하며 오답마다 이유를 안내한다. 저장된 문제와 기록은 미션 다시 하기로 함께 초기화한다.
- 갤러리: 힘의 표현과 평형 → 중력 → 탄성력 → 마찰력 → 부력 → 알짜힘과 운동 상태 변화. 미구현 실험실은 준비 중으로 표시한다. 기존 2개에 모드 링크와 버전에 맞는 미션 점을 제공한다.

## 창의 장치와 한계
- 힘의 표현: 기존의 두 힘/합력 하나 자국 겹쳐 보기. 같은 시간의 자국이 같은 운동을 보여 주며, 회전·마찰이 없는 이 모형의 범위에서 비교한다. 합력은 더해진 세 번째 힘이 아니다.
- 마찰력: 기록장의 같은 조건 재측정 점과 평균을 함께 본다. 힘 화살표는 흔들리지 않아 측정의 흔들림과 현상 자체의 변화를 구분한다. 실측 장치의 모든 오차·재료 특성을 재현하는 것은 아니다.
- 새로운 사물 비유는 추가하지 않는다. 보조 층을 꺼도 과학 모형이 완결된다.

## 검증 계획
1. 손계산: ±50/±30 N 합력 80/20 N, 40/40 N 평형, 20 N·5 kg·1초에서 v=4 m/s와 x=2 m. 마찰 면별 10/20/30/40 N의 문턱·미끄럼 힘, 정지 마찰과 멈춤의 부호.
2. 기존 점검 스크립트를 학습 모드로 다시 실행한다. 추가 스크립트로 키보드 미션, 변인 통제 실패, 예측 잠금, 저장/초기화, CSV, 그래프와 표 일치, 모드간 물리 동등성을 검사한다.
3. 두 실험실×두 모드×1920×1080/1366×768/1024×768/390×844 화면을 저장하고 검사한다. 가로 스크롤·콘솔 오류·모바일 조작·접근성을 확인한다.
4. 물리/교과서·오개념/사용성 세 관점으로 별도 반박 검토하고 결과를 남긴다.
