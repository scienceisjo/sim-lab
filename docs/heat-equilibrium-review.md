# 열평형 입자 실험실 검토 보고

비상교육 p.84–88. 두 판의 정리본을 함께 확인하고 하나의 실험실로 만들었다. 모형 모드는 두 처음 온도와 컵 접촉을 조작하며 입자·열 이동·시간–온도 그래프를 살펴본다. 학습 모드는 1분마다 멈추는 측정 활동, 기록장·평균·그래프·CSV, 7개 미션과 확인 문제 3개를 제공한다.

## 계산·가정·오개념 방지

물은 안팎 각 100 g, 컵 30 g이며 열용량은 안 445 J/K, 밖 418 J/K로 설정했다. 열전달 계수 2 W/K, 외부 손실 없음. 에너지 보존 두 덩어리 해석해를 고정 0.1초 간격으로 계산한다. 실험 30초가 재생 1초이며 기본 조건의 평형 온도 33.36037 ℃는 모형 설정값이지 교과서 실측값이 아니다. 0.3 ℃ 미만은 ‘열평형에 가까워짐’ 기준으로만 쓰고 두 수치를 억지로 같게 만들지 않는다. 센서는 처음 20 ℃, 응답 시간 상수 3초의 해석해이며 학습 측정에는 ±0.2 ℃를 더한 뒤 소수 첫째 자리로 반올림한다.

입자는 양쪽 각각 48개이며 크기·색·개수가 일정하다. 단단한 칸막이를 넘지 않고, 같은 질량 원판 탄성 충돌과 온도에 맞춘 평균 제곱 속력 조절로 움직임을 표현한다. 실제 물 분자 간 힘 전체를 재현하지 않는 설명 모형임을 화면에 밝혔다. 밀도표에 따른 부피 비율은 창 너비로 표현하며 입자를 없애거나 추가하지 않는다. 평균 움직임 비율은 절대온도 제곱근 비 그대로다. 찬물에서도 입자가 움직이며, 매크로 온도 변화 재생을 멈춰도 설명용 입자 움직임은 계속된다.

열의 순이동 화살표는 거시 온도 차이에 따라 방향을 정한다. 안팎을 뒤집어도 높은 온도에서 낮은 온도로 향한다. 미시 충돌의 순간 요동 때문에 방향이 뒤집히는 현상은 넣지 않았다. 열과 입자 자체의 이동을 구별한다.

창의 장치는 두 물의 움직임 비교 막대와 벽 양쪽 확대 창이다. 막대는 열량·입자 크기가 아니며 실제 비율을 과장하지 않는다. 60 ℃와 5 ℃의 움직임 크기 비는 1.09441이다. 입자 구조를 실제 물의 사진처럼 받아들이지 않도록 확대·시간·분자 모형 한계를 설명했다.

## 수치 대조

| 조건 | 손계산 | 검증 |
|---|---|---|
| 기본 60/5 ℃, 처음 | 60/5 ℃ | 일치 |
| 1분 뒤 | 안 48.626791 ℃, 밖 17.107842 ℃ | 일치 |
| 10분 뒤 | 안 33.462141 ℃, 밖 33.252027 ℃ | 일치 |
| 충분히 긴 시간의 평형 | 33.360371 ℃ | 해석해 일치 |
| 온도 차이의 시간 상수 | 107.769409초 | 일치 |
| 따로 둔 물 | 물의 온도는 처음과 동일 | 일치 |
| 60/5 ℃의 입자 움직임 비 | √(333.15/278.15)=1.094411 | 일치 |

두 모드에서 5·60·80 ℃ 조합, 접촉/분리 총 36조건을 검산했다. 물·컵의 에너지 보존 10⁻⁷ 이내, 해석해 온도 10⁻⁸ 이내였다. 5/80→80/5→33/33 ℃ 조건에서 입자 48개씩 유지, 경계 이탈 없음, 평균 제곱 속력 비 일치를 확인했다.

## 미션과 화면

실제 키보드·클릭·재생으로 7/7 통과: 온도 탐색, 60/5 ℃ 10분 관찰, 평형 근처 입자 예상, 안팎 바꾸기, 시간에 따른 온도 변인 설계, 접촉식 센서 기다리기, 열 이동 정리. 확인 문제는 찬물의 입자, 반대 배치의 열 이동, 온도계 기다리기로 3/3 통과했다. 예상 전 재생 잠금과 같은 시각 반복 기록만으로 변인 미션 통과 불가도 검사했다.

## 세 관점 자체 반박 검토

- 물리: 시간 간격을 빠뜨린 열량 계산, 입자 수 변경, 칸막이 통과, 평형에서 입자가 정지하는 오류를 방지했다. 작은 온도 차이를 이유로 정확한 두 온도를 강제 일치시키지 않는다.
- 교과서·오개념: 60/5 ℃·10분 관찰과 접촉식 온도계 기다리기를 연결했다. 물 양·비열 조작은 후속 단원으로 넘겼다. 안팎 반전으로 열의 방향을 위치에 외우는 오해를 방지했다. 실제 비율을 왜곡하는 빠르기 강조 대신 비교 막대를 썼다.
- 사용성: 학습은 1분마다 자동 정지한다. 모바일의 그래프 눈금·축 제목·입자 설명 겹침을 수정하고 전체 검증을 다시 실행했다. 공통 기록장과 그래프 데이터 표를 제공한다.
