# 온도·전도·대류 표현 재설계

사용자 지시: 뜨거운 부분과 찬 부분을 입자 색으로 구별하고, 전도는 이웃 입자의 진동 상호작용, 대류는 온도 차이에 따른 유체 이동을 이해할 수 있게 다시 만든다. 기준은 9과03-01·02, 비상교육 p.84–94와 기존 온도 관련 실험실의 범위다.

## 구현 기준

- 색은 고정된 섭씨 눈금에 연결한다. 순간 속도를 입자 하나의 온도로 부르지 않는다. 색은 해당 부분의 평균 온도를 나타내는 설명용 표시다. 입자 크기와 개수는 온도 때문에 바뀌지 않는다.
- 고체 확대창: 고정 평형 위치 부근의 두 방향 변위·속도를 적분한다. 이웃 입자 사이 조화력과 평형점 복원력을 함께 계산하며, 동일 위상의 사인파를 지연시켜 그리지 않는다. 결합선과 진동 폭·시간은 설명용 확대다. 금속의 자유 전자에 의한 전도는 별도로 밝힌다.
- 확대창의 국소 Langevin 열저장고는 거시 모형 온도와 연결한다. 확대창의 입자 운동 자체로 실제 금속의 전도 계수를 예측한다고 주장하지 않는다. 독립된 저장고 없는 경우 에너지 보존과 이웃으로의 전달을 검사한다.
- 대류: 냄비 안 18×12 칸에 열용량을 배분하고 이웃 칸 사이 전도·물의 이동에 의한 열 운반을 보존형 유한체적으로 계산한다. 온도장과 표지는 같은 좌표를 사용한다. 가운데가 가열되고 가운데에서 상승, 벽 쪽에서 하강한다.
- 대류 속도는 부력과 저항의 평균 운동 방정식으로 정하며 닫힌 두 순환의 유선함수를 사용한다. 전체 유체 운동 방정식을 푼 실제 냄비 재현은 아니다. 유체 표지는 분자가 아니라 물 덩어리다. 물 분자의 열운동과 대류 속도를 혼동시키지 않는다.
- 복사는 입자가 열을 옮기는 그림으로 바꾸지 않는다. 기존 온도의 네제곱에 따른 교환 계산과 왕복 경로, 순이동을 유지한다.

## 검증

고체 미시 모형의 에너지 보존·국소 교란 전달·안정성을 검증한다. 대류 모형은 같은 온도 유지, 유속장의 발산 0, 유체와 냄비를 합친 에너지 보존, 흐름을 막았을 때 위쪽 가열 차이, 시간 간격 수렴을 검증한다. 두 모드·기존 미션 회귀와 네 화면 검증도 수행한다.

기존 입자 모형 중 열평형·열팽창·기체는 계산 온도와 동일한 색을 사용한다. 온도가 정의되지 않은 분류 모형이나 물질의 종류를 나타내는 색을 임의 온도색으로 바꾸지 않는다.
