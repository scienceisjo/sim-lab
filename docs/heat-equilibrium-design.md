# 열평형 입자 실험실 설계 카드

## 2026-09-27 추가 수정: 보이는 운동과 장치

사용자 검토에서 입자 속력 차이가 읽히지 않고 컵·용기가 단순한 사각형처럼 보이는 문제가 드러났다. 핵심 관계는 ‘열을 주고받으면 뜨거운 물의 평균 운동은 줄고 찬물은 늘어 같은 정도에 가까워지되, 입자는 멈추지 않는다’이다. 온도 해석해와 미션은 유지한다.

입자 기준 속력을 양쪽 모두 25 → 90 모형 길이/표시초로 올리고 1/240초 고정 간격으로 충돌을 계산한다. 과거 위치를 잇는 짧은 자취, 더 큰 확대창, 공통 0점의 빠르기 비교 막대와 현재 비를 제공한다. ‘입자 크게’ 관찰 창에서는 장치·그래프 대신 입자 운동을 화면 대부분에 보여 준다. 속력 비는 절대온도의 제곱근 관계를 유지하며 섭씨 온도 비로 과장하지 않는다. 움직임 줄이기 설정은 자동 입자 애니메이션을 멈춘다.

장치는 투명 바깥 비커, 금속 안쪽 컵의 잘린 면, 분리된 두 수면, 잠긴 센서 끝과 디지털 센서 표시를 직접 캔버스로 그린다. 실제 모습의 물은 온도 때문에 붉어지지 않으며 온도색은 모형 층에만 적용한다. 컵 벽이 두 물을 분리하는 단면임을 표시한다. 센서는 기존 응답 지연을 그대로 반영한다.

창의 장치의 한계: 자취는 입자의 최근 실제 모형 위치이고 열이 흐르는 선이 아니다. 막대는 무작위 입자 집단의 대표 속력(RMS)으로 계산하며 입자 하나의 순간 속력과 구별한다. 설명용 시간·길이 배율을 키운 것이며 실제 물의 분자 운동 속도나 유체 분자 간 힘 전체를 재현하지 않는다.

근거: 두 판의 열의 이동 정리본 p.84–88을 함께 대조한다. 모형은 섞이지 않는 두 물의 입자 창, 알루미늄 컵 벽을 사이에 둔 열 이동, 시간–온도 곡선이다. 초기 안쪽/바깥 온도(각 5~80 ℃)와 접촉 여부가 핵심 조작이다. 안팎 온도를 뒤집을 수 있어 열의 방향이 위치에 고정되지 않는다.

각 물 100 g, 안쪽 알루미늄 컵 30 g. 내부 열용량은 445/418 J/K, 접촉 열전달 계수 2 W/K다. 외부로 새는 열은 생략한 단열 모형이다. 교과서의 실제 결과 수치가 아니라 에너지 보존과 10분 관찰을 설명하는 설정값임을 밝힌다. 두 덩어리 사이 해석해를 0.1초 고정 간격으로 계산하여 에너지 보존·단조 수렴을 보장한다. 열평형 접근의 화면 기준은 차이 0.3 ℃ 미만이며 실제로 완전히 같은 온도인 것은 아님을 구분한다. 센서의 응답은 시간 상수 3초인 지연 모형이고 처음에는 20 ℃다. 초기 센서 표시와 충분히 기다린 표시를 비교하는 미션을 둔다.

입자는 양쪽 각 48개, 크기·개수를 유지하며 색은 평균 온도에 연결하고 컵 벽을 넘지 않는다. 원판 충돌은 같은 질량의 탄성 충돌을 쓰고 운동 크기는 계산된 절대온도의 제곱근에 맞춘다. 물의 분자 구조·상호 작용 전체를 재현하는 엔진은 아니며 온도와 움직임을 연결하는 설명 층임을 밝힌다. 간격은 주어진 물 밀도표에 따라 용기 창의 너비만 바꾸어 나타내고, 입자는 생성·소멸하지 않는다. 기본은 실제 부피 비율이며 간격 차이 강조는 추가하지 않는다. 평균 움직임 비교 막대로 작은 실제 비율 차이를 읽게 한다. 찬물에서도 계속 움직이며 온도 변화 재생을 멈춰도 입자 설명 움직임은 계속된다.

학습 모드에서는 1분마다 자동으로 멈춰 측정하게 한다. 기록은 초기 조건·시간·센서 온도를 담고 ±0.2 ℃ 흔들림을 반올림한다. 모형값과 센서 응답을 분리하여 표시한다. 미션은 온도 탐색, 60/5 ℃ 10분 관찰, 평형 가까이에서 입자 예상, 안팎 바꾸기, 시간에 따른 온도 변인 설계, 접촉식 센서 기다리기, 열 이동 정리다. 확인 문제 3개를 둔다.

창의 장치: 두 물의 입자 움직임 비교 막대와 벽 양쪽을 확대하는 창. 막대 비는 제곱근 절대온도 비를 그대로 따른다. 막대는 열의 양이나 입자 크기를 뜻하지 않는다. 열 화살표는 입자 충돌의 순간 요동에서 구하지 않고 거시 온도 차이로 방향을 정한다. 평형에 가까워지면 순이동이 작아진다는 문장으로 표시하며, 입자가 멈춘다고 표현하지 않는다.
