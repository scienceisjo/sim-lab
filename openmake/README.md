# 오픈메이크랩

학생용 입구: https://scienceisjo.github.io/sim-lab/openmake/

현재 활동은 「야! 나 여기 있어! — 0과 1의 구조 작전」입니다. 정보를 0과 1로 표현하고 공통 약속으로 해석하는 스토리 게임입니다.

- index.html: 독립 허브
- games/binary-buddy.html: 검증된 v11-10d 게임과 허브 복귀 링크
- assets/: 허브 미리보기 및 아이콘
- downloads/: 교사용 운영 안내, 오프라인 패키지, 글꼴 라이선스

이 폴더의 게임은 과학 시뮬레이션 갤러리의 공통 엔진을 사용하지 않는 별도 수업 활동입니다. 게임의 만화 미술과 음악은 교사가 승인한 기존 자료를 사용하며, 학생 계정이나 원격 데이터베이스는 사용하지 않습니다. 자유 답변과 진행은 사용하는 브라우저에만 저장됩니다.
