도안에 맞춘 제작판에 전지·저항·LED·도선을 미리 배치했습니다. 학생은 축전기와 읽기·쓰기 버튼을 놓고 다리 끝을 끌어 도선에 연결합니다. 부품과 보이는 단자는 기존 크기의 50%이며, 드래그 인식 영역은 유지했습니다. 회로와 버튼을 한 화면에 놓고 전자 이동·축전기 양쪽 극판의 전하·LED 발광을 관찰합니다. 전원 켜기/끄기와 시연용 버튼 누름 유지, 시간 정지를 지원합니다. 각 비트의 쓰기·읽기를 한 번씩 누르면 자동으로 회로를 검사합니다. 시간 멈춤이나 별도 검사 클릭은 필요 없습니다. 제작판에 검사 완료가 표시되고, 통과하면 실물 도전으로 이동할 수 있습니다. 잘못된 회로는 고칠 연결을 안내하며, 스위치의 양단을 도선으로 우회한 연결도 표시합니다. 자동 검사를 통과하면 선택한 1·2·3비트 도안을 받을 수 있습니다. 교사는 허브의 자료함에서 인쇄 자료를 내려받을 수 있습니다. 학생 계정이나 원격 데이터베이스를 사용하지 않습니다.

2026-11-11 · 조승재(과학이조선생)

시연 모형: 시간은 12배 느리며, 충전 과정을 유한하게 계산하기 위해 전원·접점 등가저항 47 Ω을 사용합니다. 이는 실제 제작에 추가하는 부품이나 특정 전지의 실측값이 아닙니다. 전자 흐름은 실제 배선의 계산 전류와 반대 방향이며, 전자가 축전기의 절연층을 통과하지 않습니다. 입자의 크기·개수·속도와 빛은 확대된 관찰 표현입니다. 기존 배치와 기록은 유지하고 새 전원 모형으로 기능 검사를 다시 진행합니다.
